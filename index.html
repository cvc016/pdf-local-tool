常見情境：該用哪個工具？

  • 報名或求職網站說附件太大：用 壓縮 PDF。掃描檔與照片型 PDF 效果最好（我們實測 5 頁掃描檔從 5.0 MB 壓到 854 KB）；Word 匯出的文字型 PDF 通常本來就小，詳見 PDF 太大無法上傳怎麼辦。
  • 手機拍了幾張收據或作業，要交一個 PDF：先用 圖片壓縮 把最長邊縮到 1920 px，再用 JPG 轉 PDF 合成，檔案會比直接用原圖小很多。
  • 只需要長篇 PDF 的其中幾頁：用 PDF 分割 輸入「1-3, 5」這樣的頁碼範圍。
  • 掃描檔順序亂掉、有的頁面倒過來：用 PDF 頁面排序，可以同時旋轉與刪頁；整理流程可參考 掃描檔整理教學。
  • 要把身分證影本傳給店家或房東：用 圖片加浮水印，寫清楚用途與日期，見 證件影本浮水印怎麼寫。
  • 店裡想讓客人掃碼連 Wi-Fi：用 QR Code 產生器 的 Wi-Fi 類型，產生的是不會過期的靜態 QR Code。

這個網站怎麼運作？

Waiting Studio 本機 PDF 是放在 GitHub Pages 上的靜態網站，沒有後端伺服器。打開工具時，處理檔案的程式會下載到您的瀏覽器執行：PDF 用 pdf-lib 與 PDF.js，圖片壓縮用 WebAssembly 版的 MozJPEG、libwebp 與 OxiPNG，QR Code 用 qrcode-generator，這些開源程式都放在本站，不從其他 CDN 載入（清單見 第三方授權）。您選擇的檔案只會讀進裝置的記憶體，處理結果直接下載，本站的程式不會把檔案交給任何第三方。

網站以 Google AdSense 顯示一個固定的橫幅廣告來負擔營運，廣告由 Google 提供並可能使用 Cookie，說明見 隱私權政策。完整原始碼公開在 GitHub，任何人都可以檢查。

使用前要知道的限制

  • 設有開啟密碼或加密的 PDF 目前無法處理。
  • 壓縮 PDF 採「頁面轉圖片」的方式，壓縮後文字無法選取，適合掃描檔，不適合需要複製文字的文件。
  • HEIC 照片需要瀏覽器本身支援才能讀取，Windows 上的 Chrome、Edge 多半不行。
  • 能處理多大的檔案取決於裝置記憶體，手機遇到上百頁的掃描檔可能會變慢或失敗。

常見問題

真的不會上傳我的檔案嗎？

是的。本站是 GitHub Pages 上的靜態網頁，沒有接收檔案的伺服器；PDF 與圖片的讀取、處理和產生都在您的瀏覽器中完成。您可以打開瀏覽器開發者工具的「網路」分頁，確認處理檔案時沒有任何上傳請求。

需要註冊或付費嗎？

不需要。所有工具免費、免註冊，也沒有每日次數限制。網站以一個固定的橫幅廣告維持營運，不使用彈出式或插頁式廣告。

手機可以用嗎？

iPhone、iPad、Android 手機與平板都可以用，建議使用 Safari 或 Chrome。頁數很多或很大的檔案在手機上會比較慢，必要時請分批處理或改用電腦。

有哪些檔案處理不了？

設有開啟密碼或加密的 PDF 目前不支援；HEIC 照片只有能解碼 HEIC 的瀏覽器（例如 Safari）才能讀取；GIF 動畫只會處理第一格。

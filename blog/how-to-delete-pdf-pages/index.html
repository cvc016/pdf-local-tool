怎麼刪除 PDF 頁面？看縮圖點選就能刪

直接回答：開啟 本機PDF 的「刪除 PDF 頁面」工具，選擇您的 PDF，在要刪除的頁面縮圖下方按 🗑，確認上方顯示的「保留 X / Y 頁」正確後，按「套用並下載 PDF」，就會下載一個刪掉那些頁面的新 PDF。原本的檔案不會被修改，按錯了也能還原。

掃描時多掃了空白頁、簡報匯出的 PDF 夾了不想給客戶看的頁面，或是只想刪掉合約裡重複的一頁，都可以這樣處理。下面依照工具上的實際按鈕說明步驟，也整理了手機操作方式與常見問題。

開啟「刪除 PDF 頁面」工具

刪除 PDF 頁面的 4 個步驟

  1. 開啟「刪除 PDF 頁面」，點一下「選擇或拖放一個 PDF 檔案」區域（電腦也可以直接把檔案拖進來）。畫面會列出檔名、總頁數與檔案大小，並顯示每一頁的縮圖。
  2. 在要刪除的頁面按 🗑，該頁縮圖會變淡、頁碼加上刪除線，按鈕變成 ↩；按錯時再按一次 ↩ 就能還原。
  3. 如果檔案裡有很多空白頁，可以按「✨ 自動標記空白頁」，工具會逐頁檢查並把空白頁標記為刪除。自動標記後請再看一次縮圖，想從頭來過可以按「復原全部」。
  4. 確認「保留 X / Y 頁」的數字正確後，按「套用並下載 PDF」。新檔案的檔名是原檔名加上「_已刪除頁面」。

用手機刪除 PDF 頁面

手機上不用安裝 App，用瀏覽器開啟工具頁即可。iPhone 建議用 Safari：點選上傳區域後，從「檔案」App 選擇 PDF；如果 PDF 是在 LINE 或郵件裡收到的，請先用分享功能把它存到「檔案」App。縮圖在手機上會排成多欄，捲動時才會陸續顯示，直接點縮圖下方的 🗑 即可標記刪除。

按下「套用並下載 PDF」後，Safari 會下載新檔案，依照您的設定，通常會存到「檔案」App 的「下載項目」資料夾；如果找不到，可以點 Safari 網址列附近的下載圖示查看。Android 手機用 Chrome 操作方式相同，檔案一般會存到「下載」資料夾。

「自動標記空白頁」怎麼判斷？

按下「✨ 自動標記空白頁」後，工具會把每一頁縮小繪製，計算「不是接近白色」的像素佔整頁的比例；比例低於千分之三的頁面，就視為空白頁並標記刪除。完成後會提示標記了幾頁，若沒有找到，會顯示「沒有找到空白頁」。

因為是看畫面判斷，掃描時帶到的淡淡紙紋通常仍會被當作空白，但有頁碼、頁首或少量文字的頁面，可能就不會被標記；反過來說，內容非常少、顏色很淡的頁面，也有可能被標記。自動標記只是幫您先勾選，下載前一定要再看一次縮圖，不需要刪的頁面按 ↩ 還原即可。

要刪很多頁、只留幾頁時怎麼做？

如果一份 100 頁的檔案只想留下其中 3 頁，一頁一頁按 🗑 會很累。這時可以改用 PDF 分割：在「頁碼範圍」輸入要保留的頁碼（例如「2, 5, 10」），或直接點選縮圖選取頁面，再勾選「將所選頁面合併成單一檔案（擷取頁面）」，按「分割 PDF 並下載」，就會得到只包含這幾頁的 PDF。

刪除頁面時，也能順便旋轉或排序

刪除頁面工具的每一頁縮圖下方，除了 🗑，還有 ↺（向左轉）、↻（向右轉）和 ⠿（拖曳排序）。所以發現某一頁是倒的，可以在同一個畫面轉正；想調整頁面順序，用滑鼠拖曳縮圖，手機請按住 ⠿ 拖曳。如果主要目的是旋轉，可以參考 PDF 旋轉後儲存教學；主要是排序，則可以用 PDF 頁面排序，它多了「反轉順序」按鈕。

使用時的幾個限制

  • 一次處理一個 PDF。要處理下一份，按「換一個檔案」即可。
  • 至少要保留 1 頁；全部頁面都標記刪除時，「套用並下載 PDF」按鈕無法按。
  • 有密碼保護或已加密的 PDF 目前不支援，會顯示無法讀取的提示，請先用原本的軟體移除密碼。
  • 刪除頁面只是把保留的頁面複製到新檔案，不會重新壓縮內容，文字仍可選取與搜尋。

常見問題

檔案會上傳到伺服器嗎？

不會。讀取 PDF、偵測空白頁與產生新檔案都是由您手機或電腦上的瀏覽器執行，本站是放在 GitHub Pages 的靜態網頁，沒有接收檔案的伺服器。網頁的內容安全政策（CSP）也限制只能連線到本站，您可以用電腦瀏覽器的開發者工具，在「網路」分頁確認處理過程沒有上傳請求。

安全嗎？會不會被別人看到？

檔案只會被讀進您裝置的記憶體，處理結果直接下載到您的裝置，本站無法取得檔案內容。本站不使用 Cookie、不做追蹤分析，也不載入第三方腳本。要注意的是裝置本身的安全：在公用電腦或借來的手機上使用時，處理完記得把下載的檔案刪除。

檔案大小有限制嗎？

本站的程式沒有設定檔案大小或數量的上限。實際能處理多大的檔案，取決於您裝置的記憶體與瀏覽器；手機的記憶體通常比電腦少，檔案很大時可能會比較慢，甚至處理失敗，這時可以改用電腦，或把檔案分批處理。

需要註冊或付費嗎？

不需要。打開網頁就能用，不需要帳號、Email，也不用安裝 App；工具免費使用，本站沒有設定每天的使用次數限制。

刪錯頁面還能救回來嗎？

可以。下載前按 ↩ 就能還原單一頁面，按「復原全部」會清除所有刪除與旋轉設定。本工具也不會修改原始檔案，而是另外產生一個新的 PDF，原檔仍保留在您的裝置上，隨時可以重新處理。

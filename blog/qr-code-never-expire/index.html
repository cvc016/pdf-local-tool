QR Code 會過期嗎？做一個永久有效的靜態 QR Code

直接回答：QR Code 圖案本身不會過期，會「過期」的是動態 QR Code 背後的轉址服務。用「QR Code 產生器」選「網址」，貼上您的網址，下載 PNG 或 SVG，得到的是靜態 QR Code：網址直接編碼在圖案裡，掃描時不經過任何第三方伺服器，只要您的網址還在，就永久有效，也不需要註冊或登入。

常見的情況是：在某個網站「免費」做了 QR Code，印在店門口、菜單或名片上，幾週後掃描卻出現「方案已到期，請升級」的頁面。這不是 QR Code 壞了，而是那個網站產生的是動態碼，掃描時要先連到他們的短網址，他們停止轉址，您的 QR Code 就跟著失效。

開啟「QR Code 產生器」工具

產生永久有效 QR Code 的 4 個步驟

  1. 開啟「QR Code 產生器」，內容類型選「網址」（也可以選文字、Wi-Fi、名片、LINE 或轉帳資訊）。
  2. 貼上完整網址，例如 https://example.com/menu。沒有輸入 https:// 時會自動補上。右側會即時顯示 QR Code，展開「QR Code 內容」可以確認實際編碼的文字。
  3. 視需要調整前景色、背景色，或上傳 Logo；放 Logo 時會自動使用最高容錯 H。
  4. 按「下載 PNG」或「下載 SVG（向量）」，並在印刷前用兩支以上的手機實際掃描測試。

用手機產生 QR Code

在 iPhone 用 Safari、Android 用 Chrome 開啟 QR Code 產生器，輸入網址後按「下載 PNG」。iPhone 下載的圖片在「檔案」App 的「下載項目」，可以分享到「照片」或直接傳到 LINE；Android 則在「下載」資料夾。要確認能不能掃，可以把畫面給另一支手機的相機掃描看看。

靜態 QR Code 和動態 QR Code 有什麼不同？

  • 靜態 QR Code：內容（網址、文字）直接存在黑白方格裡。掃描時手機直接讀出您的網址，不經過任何中間服務，所以不會過期，也沒有人能追蹤掃描次數。缺點是印出後不能修改內容。
  • 動態 QR Code：圖案裡存的是服務商的短網址，掃描時先連到服務商，再轉到您設定的網址。好處是可以事後改目的地、看掃描統計；代價是必須一直依賴該服務，停止付費或服務關閉時就失效，掃描者的資訊也會經過第三方。

怎麼判斷手上的 QR Code 是不是動態碼？

用手機相機掃描時先不要點開，看一下顯示的網址：如果是您自己的網域，就是靜態碼；如果是陌生的短網址（例如某某 QR 服務的網域），就是動態碼，建議重新產生一個靜態版本替換。

想保留「可以改網址」的彈性怎麼辦？

可以讓靜態 QR Code 指向一個您自己能管理的網頁，例如官網上的「/menu」頁面或社群帳號的固定連結。之後要更新內容時，修改那個網頁即可，QR Code 不用重印，也不必依賴任何 QR Code 服務商。

印刷前的檢查清單

  • 深色前景、淺色背景，對比要足夠；避免反白或淡色。
  • QR Code 四周保留空白邊（本工具輸出時已預留）。
  • 印刷尺寸建議至少 2 公分見方；海報等遠距離掃描要更大。印刷請用 SVG 或 2048 px 的 PNG。
  • 網址越短，圖案越簡單、越好掃。

常見的使用情境

餐廳菜單、店家官網、Google 地圖評論頁、活動報名表單、產品說明書、名片上的作品集連結，都很適合用靜態 QR Code。這些內容通常會使用好幾年，一旦印刷出去就很難全部回收，所以「不依賴任何服務商」特別重要。除了網址，也可以把電子名片（vCard）做成 QR Code，對方掃描後能直接存進聯絡人；或把 LINE ID 做成加好友的 QR Code，放在店內與傳單上。若要提供轉帳資訊，可選「轉帳資訊」類型產生純文字 QR Code，對方掃描後複製帳號即可，但它不是銀行的付款碼。

顏色與 Logo 會影響掃描嗎？

會。手機是靠明暗對比辨識方格，所以前景一定要比背景深，淺灰、淺黃或反白的設計常常掃不到；本工具偵測到對比不足時會提醒您。放 Logo 等於遮掉中間一部分圖案，需要靠容錯能力補回來，因此放 Logo 時會自動使用最高的 H 容錯，Logo 也只佔中央約兩成面積。設計完成後，請一定用不同品牌的手機實際掃描。

常見問題

輸入的網址會上傳嗎？

不會。QR Code 是在您的瀏覽器中計算產生，本站沒有接收資料的伺服器，也不會記錄您產生了什麼內容。

需要註冊或付費嗎？

不需要。打開網頁就能用，不需要帳號、Email，也不用安裝 App；工具免費使用，本站沒有設定每天的使用次數限制。

靜態 QR Code 可以看掃描次數嗎？

不行。因為掃描不經過任何伺服器，所以沒有統計；需要統計時，可以在網址加上您自己分析工具的追蹤參數（例如 UTM）。

可以商業使用、印在商品上嗎？

可以，產生的圖片不加浮水印，可自由用於商業用途。

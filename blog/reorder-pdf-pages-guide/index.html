PDF 頁面順序調整教學：拖曳縮圖重排、一鍵反轉

直接回答：開啟「PDF 頁面排序」，選擇 PDF 後每一頁會顯示成縮圖，用滑鼠把縮圖拖到新位置（手機請按住縮圖右下角的 ⠿ 再拖曳），排好後按「套用並下載 PDF」，就會得到新順序的檔案。整份順序剛好顛倒時，按「反轉順序」一次就能倒過來；排亂了可以按「復原全部」重來。

頁面順序出錯，通常發生在掃描、合併多份檔案，或是別人傳來的 PDF 附件放錯位置。看著縮圖排，比輸入頁碼更不容易出錯。

開啟「PDF 頁面排序」工具

調整 PDF 頁面順序的 4 個步驟

  1. 開啟「PDF 頁面排序」，選擇或拖曳一個 PDF 進來，畫面會列出每一頁的縮圖。
  2. 把縮圖拖到想要的位置：電腦直接用滑鼠拖曳；手機請按住縮圖右下角的 ⠿，拖到畫面邊緣時頁面會自動捲動。
  3. 整份順序顛倒時按「反轉順序」；排錯了按「復原全部」回到原始順序。需要的話也可以在同一畫面旋轉或用 🗑 刪除頁面。
  4. 確認無誤後按「套用並下載 PDF」，下載排好順序的新檔案；原始檔案不會被修改。

手機排序的訣竅

手機畫面小，直接在縮圖上滑動會變成捲動頁面，所以拖曳要從右下角的 ⠿ 開始。頁數多時，可以先把要移動的頁面拖到畫面上緣或下緣，等畫面自動捲到目標附近再放開。若要大幅度移動很多頁，在電腦上操作會比較輕鬆。

iPhone 請用 Safari、Android 請用 Chrome 開啟，下載的檔案分別在「檔案」App 的「下載項目」與「下載」資料夾。

雙面掃描的順序怎麼救？

很多事務機在單面送紙時，會先掃完所有正面，再翻過來掃背面，背面常常變成倒序。處理方式：先確認背面那段的順序，若整份完全顛倒，用「反轉順序」；若只有一段倒過來，就用拖曳把那幾頁逐一放回正確位置。頁數很多時，也可以先用 PDF 分割 把正面與背面拆成兩份，分別整理後再合併。

多份檔案要怎麼排？

排序工具一次處理一個 PDF。如果要把幾份檔案的頁面交錯排列，先用 PDF 合併 合成一份，再到排序工具調整，手機上的合併做法可以參考 手機 PDF 合併教學。

排序會影響畫質嗎？

不會。排序只是改變頁面在檔案中的先後，頁面內容直接沿用，文字仍可選取與搜尋。有密碼保護或已加密的 PDF 目前無法處理，請先用原本的軟體移除密碼。

常見問題

檔案會上傳到伺服器嗎？

不會。讀取 PDF、依新順序組合頁面與產生新檔案都是由您手機或電腦上的瀏覽器執行，本站是放在 GitHub Pages 的靜態網頁，沒有接收檔案的伺服器。網頁的內容安全政策（CSP）也限制只能連線到本站，您可以用電腦瀏覽器的開發者工具，在「網路」分頁確認處理過程沒有上傳請求。

安全嗎？會不會被別人看到？

檔案只會被讀進您裝置的記憶體，處理結果直接下載到您的裝置，本站無法取得檔案內容。本站不使用 Cookie、不做追蹤分析，也不載入第三方腳本。要注意的是裝置本身的安全：在公用電腦或借來的手機上使用時，處理完記得把下載的檔案刪除。

檔案大小有限制嗎？

本站的程式沒有設定檔案大小或數量的上限。實際能處理多大的檔案，取決於您裝置的記憶體與瀏覽器；手機的記憶體通常比電腦少，檔案很大時可能會比較慢，甚至處理失敗，這時可以改用電腦，或把檔案分批處理。

需要註冊或付費嗎？

不需要。打開網頁就能用，不需要帳號、Email，也不用安裝 App；工具免費使用，本站沒有設定每天的使用次數限制。

排序時可以順便刪頁嗎？

可以。每頁縮圖下有 🗑，按下就會標記刪除。如果主要目的是刪頁，也可以參考 怎麼刪除 PDF 頁面。

排序後的檔名會是什麼？

下載的是一個新的 PDF，原始檔案不會被覆蓋。若要繳交或寄出，建議下載後依用途重新命名，例如加上日期或文件名稱，方便對方辨識。

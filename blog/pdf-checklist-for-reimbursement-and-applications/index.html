報帳、申請文件 PDF 整理清單

直接回答：先把紙本收據或證件拍照，用 圖片轉 PDF 轉成 PDF；再把申請表、證明文件、收據 PDF 用「PDF 合併」依規定順序合成一份；最後檢查有沒有多餘頁面、方向是否正確、檔名是否符合要求。這些步驟都能在瀏覽器裡完成，含有個資的文件不必上傳到別人的伺服器。

每個單位對檔案格式、順序和命名的規定都不一樣，本文提供的是通用的整理流程，實際要求請以公司財務、學校或主辦單位的公告為準。

開啟「PDF 合併」工具

整理報帳或申請 PDF 的 4 個步驟

  1. 列出要繳交的文件與規定順序，例如：申請表 → 身分證明 → 證明文件 → 收據。把紙本文件放在光線充足、背景單純的桌面拍照。
  2. 用「圖片轉 PDF」一次選取收據或證件照片，排好順序，紙張選 A4 方便對方列印，按「轉換成 PDF 並下載」。
  3. 用「PDF 合併」選取所有 PDF，用 ▲▼ 或 ⠿ 依規定順序排列，按「合併 PDF 並下載」。新檔名預設是第一個檔案名稱加「_合併」，請依規定改名。
  4. 打開合併好的檔案逐頁檢查：多餘頁面用「刪除 PDF 頁面」移除，方向不對用「PDF 旋轉」轉正並儲存。

只有手機也能完成

所有步驟都可以在手機瀏覽器操作。拍照時把文件四角都拍進去，拍完先在相簿裁切；若收據是感熱紙，字跡容易褪色，建議盡早拍照留存。PDF 合併的手機操作細節可參考 手機 PDF 合併教學，照片轉 PDF 可參考 手機多張照片合成 PDF。

繳交前的檢查清單

  • 頁數與順序：和規定逐項核對，封面或申請表通常放第一頁。
  • 每頁都看得清楚：金額、日期、統一編號、章戳要能辨識，模糊的重拍。
  • 方向一致：沒有躺平或倒過來的頁面。
  • 沒有多餘內容：不相關的頁面、其他人的資料要移除。
  • 檔名：依規定命名，例如姓名加日期，避免只用「合併」這類看不出內容的名稱。
  • 檔案大小：確認符合上傳系統的限制。本站目前沒有壓縮功能，若太大可以減少照片張數、先縮小照片，或詢問承辦單位能否分檔上傳。

敏感資料的處理

報帳與申請文件常含有身分證字號、銀行帳號、地址等資料。使用不需上傳的工具可以降低外流風險，但仍要注意：在公用電腦處理完記得刪除下載的檔案；寄送時確認收件人正確。若文件要求遮蔽部分資訊，本站目前沒有遮蔽或塗黑功能，請用其他方式處理後再合併。

常見問題

檔案會上傳到伺服器嗎？

不會。照片轉換與合併都是由您手機或電腦上的瀏覽器執行，本站是放在 GitHub Pages 的靜態網頁，沒有接收檔案的伺服器。網頁的內容安全政策（CSP）也限制只能連線到本站，您可以用電腦瀏覽器的開發者工具，在「網路」分頁確認處理過程沒有上傳請求。

安全嗎？會不會被別人看到？

檔案只會被讀進您裝置的記憶體，處理結果直接下載到您的裝置，本站無法取得檔案內容。本站不使用 Cookie、不做追蹤分析，也不載入第三方腳本。要注意的是裝置本身的安全：在公用電腦或借來的手機上使用時，處理完記得把下載的檔案刪除。

需要註冊或付費嗎？

不需要。打開網頁就能用，不需要帳號、Email，也不用安裝 App；工具免費使用，本站沒有設定每天的使用次數限制。

有密碼保護的 PDF 可以合併嗎？

目前不支援有密碼保護或已加密的 PDF。請先用原本的軟體移除密碼，或請發文單位提供未加密的版本。

收據要一張一頁，還是多張放同一頁？

本站的圖片轉 PDF 是每張圖片一頁。若單位要求多張收據排在同一頁，可以先把收據並排放好拍成一張照片，再轉成 PDF；實際格式請以財務或承辦單位的規定為準。

合併後還能調整順序嗎？

可以。若合併後才發現順序不對，可以用 PDF 頁面排序拖曳縮圖重新排列，再下載新的檔案，不需要從頭合併。

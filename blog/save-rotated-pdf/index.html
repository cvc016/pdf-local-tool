PDF 旋轉後怎麼儲存？讓方向固定不再跑掉

直接回答：開啟 Waiting Studio 本機 PDF 的「PDF 旋轉」工具，選擇 PDF，在方向不對的頁面按 ↺（向左轉）或 ↻（向右轉），整份都要轉時按「全部向左轉」或「全部向右轉」，確認後按「套用並下載 PDF」。下載的新檔案已經把方向寫進 PDF 裡，之後用其他閱讀器或手機開啟，頁面都會維持您設定的方向。

很多人遇過這種情況：在閱讀器裡把頁面轉正了，關掉再打開又變回橫的。這是因為部分閱讀器的「旋轉」只改變當下的顯示方式，並沒有存回檔案；即使有儲存選項，不同軟體的做法也不一樣。要確保方向固定，最直接的方法就是產生一個已經轉好方向的新 PDF。

開啟「PDF 旋轉」工具

PDF 旋轉並儲存的 4 個步驟

  1. 開啟「PDF 旋轉」，點一下「選擇或拖放一個 PDF 檔案」區域，選擇要調整的 PDF。畫面會顯示每一頁的縮圖。
  2. 在方向不對的頁面按 ↺ 或 ↻，每按一次轉 90 度，縮圖會立即顯示轉動後的方向；需要轉 180 度就同一個方向按兩次。整份檔案方向都錯時，按上方的「↺ 全部向左轉」或「↻ 全部向右轉」。
  3. 檢查所有縮圖的方向。轉錯了可以反方向再按一次，或按「復原全部」回到原本的狀態。
  4. 按「套用並下載 PDF」，下載旋轉後的新檔案，檔名是原檔名加上「_已旋轉」。

用手機旋轉 PDF 並儲存

手機也能用，不需要安裝 App。iPhone 建議用 Safari 開啟工具頁，點選上傳區域後從「檔案」App 選擇 PDF；在 LINE 或郵件中收到的 PDF，請先用分享功能存到「檔案」App。接著在方向不對的頁面點 ↺ 或 ↻，再按「套用並下載 PDF」。

下載的檔案依照 Safari 設定，通常會存到「檔案」App 的「下載項目」資料夾；如果找不到，可以點 Safari 網址列附近的下載圖示查看。建議在「檔案」App 裡打開新檔案，確認方向正確後，再傳給別人或刪除舊檔。Android 手機用 Chrome 操作方式相同，檔案一般會存到「下載」資料夾。

為什麼這樣儲存後方向就固定了？

PDF 的每一頁都有一個「旋轉角度」的設定，閱讀器開啟檔案時會依照這個角度顯示頁面。本工具按下「套用並下載 PDF」時，會把您調整的角度加到每一頁原本的旋轉角度上，寫進新的 PDF 檔案裡。因為方向已經記錄在檔案本身，換一台電腦、換一個閱讀器，或在手機上打開，都會依照這個角度顯示。

旋轉會不會影響畫質？

不會。本工具只修改頁面的旋轉角度設定，不會重新繪製頁面，也不會把頁面轉成圖片，所以文字仍然可以選取、搜尋，圖片畫質也和原檔一樣。原本的檔案不會被修改，新檔案是另外下載的，如果轉錯了，可以用原檔重新處理。

只轉其中一頁可以嗎？

可以。每一頁縮圖下方都有自己的 ↺ ↻ 按鈕，只會轉動那一頁，其他頁面不受影響。這很適合處理「整份直向文件中夾了幾張橫向表格」的情況：只把表格頁轉正，其他頁面維持原樣。

旋轉時也能刪頁、排序

PDF 旋轉工具的每一頁縮圖下方，還有 🗑（刪除）和 ⠿（拖曳排序）。所以同一個畫面裡，可以把多餘的頁面刪掉、把順序調整好，再一次下載。畫面上方會顯示「保留 X / Y 頁」，方便確認。若主要是要刪頁，可以參考 怎麼刪除 PDF 頁面；主要是排序，則可以用 PDF 頁面排序。

常見情境

  • 掃描時紙張放反：整份都上下顛倒時，按兩次「全部向右轉」，就是轉 180 度。
  • 手機拍照轉成的 PDF 有幾頁躺平：只在那幾頁按 ↺ 或 ↻。如果是從照片轉 PDF，也可以參考 iPhone 照片轉 PDF 教學，轉換時就會依照片的拍攝方向轉正。
  • 多份 PDF 合併後才發現方向不一：先用 PDF 合併 合成一份，再到 PDF 旋轉逐頁調整。

有密碼保護或已加密的 PDF 目前無法處理，請先用原本的軟體移除密碼後再旋轉。

常見問題

檔案會上傳到伺服器嗎？

不會。讀取 PDF、寫入新的頁面方向與產生新檔案都是由您手機或電腦上的瀏覽器執行，本站是放在 GitHub Pages 的靜態網頁，沒有接收檔案的伺服器。網頁的內容安全政策（CSP）也限制只能連線到本站，您可以用電腦瀏覽器的開發者工具，在「網路」分頁確認處理過程沒有上傳請求。

安全嗎？會不會被別人看到？

檔案只會被讀進您裝置的記憶體，處理結果直接下載到您的裝置，本站無法取得檔案內容。本站不使用 Cookie、不做追蹤分析，也不載入第三方腳本。要注意的是裝置本身的安全：在公用電腦或借來的手機上使用時，處理完記得把下載的檔案刪除。

檔案大小有限制嗎？

本站的程式沒有設定檔案大小或數量的上限。實際能處理多大的檔案，取決於您裝置的記憶體與瀏覽器；手機的記憶體通常比電腦少，檔案很大時可能會比較慢，甚至處理失敗，這時可以改用電腦，或把檔案分批處理。

需要註冊或付費嗎？

不需要。打開網頁就能用，不需要帳號、Email，也不用安裝 App；工具免費使用，本站沒有設定每天的使用次數限制。

用其他軟體開啟時，方向還會正確嗎？

頁面方向是用 PDF 標準的頁面旋轉設定寫進檔案，一般的 PDF 閱讀器都會依照這個設定顯示。建議下載後先用您平常使用的閱讀器打開確認一次。

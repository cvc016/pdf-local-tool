PDF 太大無法上傳怎麼辦？不上傳檔案的 PDF 壓縮教學

直接回答：開啟 Waiting Studio 本機 PDF 的「PDF 壓縮」，選擇要壓縮的 PDF，壓縮程度先選「標準」，按「壓縮 PDF 並下載」，畫面會顯示壓縮前後的大小。還是太大時改選「強力」，黑白文件再勾選「轉成灰階」。整個過程在您的瀏覽器中完成，檔案不會上傳到任何伺服器，適合含有身分證、成績單、薪資單等個人資料的文件。

報名考試、申請補助、投遞履歷或上傳報帳單據時，系統常常限制每個附件的大小，超過就無法送出。各平台的上限不同而且可能調整，請以您上傳的網站說明為準。下面說明壓縮的步驟、各種程度怎麼選，以及哪些情況不適合壓縮。

開啟「PDF 壓縮」工具

把 PDF 壓縮到符合上傳限制的 4 個步驟

  1. 開啟「PDF 壓縮」頁面，點一下虛線區域選擇 PDF，或直接把檔案拖曳進來。讀取成功後，畫面上方會顯示檔名、頁數與目前的檔案大小，先記下這個數字，方便和壓縮結果比較。
  2. 選擇壓縮程度：「輕度」以 200 DPI 重新繪製頁面，畫質最好；「標準」為 144 DPI，是大多數文件的平衡點；「強力」為 96 DPI，檔案最小，但小字可能變得不那麼銳利。第一次建議先用「標準」。
  3. 如果文件本來就是黑白的，例如掃描的申請書、合約或成績單，可以勾選「轉成灰階」。去掉色彩資訊後，同樣的解析度通常還能再小一些。
  4. 按「壓縮 PDF 並下載」。完成後會顯示「原大小 → 新大小」以及減少的百分比，新檔名會加上「_已壓縮」。若結果沒有比原檔小，畫面會提醒您直接使用原檔，這時就不需要下載壓縮版本。

在手機上壓縮 PDF

手機不需要安裝 App。用 iPhone 的 Safari 或 Android 的 Chrome 開啟 PDF 壓縮頁面，點選上方區域後從「檔案」App、下載資料夾或雲端硬碟挑選 PDF，接下來的操作和電腦相同。iPhone 下載完成後，檔案會在「檔案」App 的「下載項目」；Android 通常在「下載」資料夾。

手機的記憶體比電腦少，頁數很多的掃描檔處理起來會比較慢。如果畫面停住或分頁重新載入，可以先用 PDF 分割 把檔案拆成幾份，分別壓縮後再上傳，或改用電腦處理。

這個 PDF 壓縮是怎麼運作的？

本工具用開源的 PDF.js 在瀏覽器裡把每一頁畫成圖片，依您選的解析度與品質編碼成 JPG，再用 pdf-lib 把這些圖片組成新的 PDF。因為每一頁都變成大小適中的圖片，原本由高解析度掃描或手機照片組成的 PDF，通常能縮小很多；實際能縮小多少，取決於原始檔的內容，本文不保證特定比例。

哪些 PDF 適合壓縮？

  • 掃描檔：用掃描器或手機掃描 App 產生的 PDF，每一頁本來就是圖片，壓縮效果通常最明顯。
  • 照片轉成的 PDF：把手機照片直接轉 PDF，每張照片可能好幾 MB，重新以適當解析度編碼後會小很多。
  • 含大量圖片的簡報或型錄：可以壓縮，但要確認圖片中的小字仍然清楚。

哪些情況不建議壓縮？

從 Word、Google 文件或 Excel 直接「另存為 PDF」的檔案，內容主要是文字與向量線條，本來就很精簡。把它轉成圖片反而可能變大，而且壓縮後文字無法再選取、複製或搜尋，超連結與可填寫的表單欄位也會消失。這類文件若太大，比較好的做法是回到原始檔，把裡面的照片縮小後重新匯出。需要讓對方複製內容、或要保留電子簽章的文件，也請保留原檔，不要使用轉圖片式的壓縮。

壓縮後還是太大怎麼辦？

可以依序嘗試：改選「強力」並勾選灰階；用 刪除 PDF 頁面 移除空白頁或不必要的附件頁；把文件拆成兩份分別上傳。如果文件是由照片組成的，也可以回到照片階段，先用 圖片壓縮 縮小，再用 JPG 轉 PDF 重新製作。

為什麼選擇不上傳的壓縮工具？

需要壓縮的文件，往往正是要交給學校、公司或政府機關的正式文件，裡面有姓名、身分證字號、地址甚至銀行帳號。很多線上壓縮服務需要把檔案上傳到對方的伺服器處理。Waiting Studio 本機 PDF 是放在 GitHub Pages 的靜態網頁，沒有接收檔案的伺服器，壓縮全程在您的裝置上進行，下載的結果也直接存在您的裝置裡。

常見問題

檔案會上傳到伺服器嗎？

不會。PDF 壓縮都是由您手機或電腦上的瀏覽器執行，本站是放在 GitHub Pages 的靜態網頁，沒有接收檔案的伺服器。網頁的內容安全政策（CSP）也限制只能連線到本站，您可以用電腦瀏覽器的開發者工具，在「網路」分頁確認處理過程沒有上傳請求。

安全嗎？會不會被別人看到？

檔案只會被讀進您裝置的記憶體，處理結果直接下載到您的裝置，本站無法取得檔案內容。本站不使用 Cookie、不做追蹤分析，也不載入第三方腳本。要注意的是裝置本身的安全：在公用電腦或借來的手機上使用時，處理完記得把下載的檔案刪除。

檔案大小有限制嗎？

本站的程式沒有設定檔案大小或數量的上限。能壓縮多少頁、實際能處理多大的檔案，取決於您裝置的記憶體與瀏覽器；手機的記憶體通常比電腦少，檔案很大時可能會比較慢，甚至處理失敗，這時可以改用電腦，或把檔案分批處理。

需要註冊或付費嗎？

不需要。打開網頁就能用，不需要帳號、Email，也不用安裝 App；工具免費使用，本站沒有設定每天的使用次數限制。

壓縮後可以再編輯文字嗎？

不行。每一頁都會變成圖片，文字無法再選取或修改。請保留原檔，之後需要修改時從原檔處理。

為什麼壓縮後畫面提醒我使用原檔？

代表壓縮結果沒有比原檔小，通常是文字型 PDF。這種檔案直接使用原檔即可；若仍超過限制，請刪除不必要的頁面或拆成兩份。

掃描檔整理教學：刪除空白頁、轉正方向、排好順序

直接回答：整理掃描檔可以照「刪空白頁 → 轉正方向 → 排順序 → 拆分或合併」的順序處理。先用「刪除 PDF 頁面」的「自動標記空白頁」找出雙面掃描產生的空白背面，確認後按「套用並下載 PDF」；方向不對的頁面用 PDF 旋轉 轉正；順序錯亂用 PDF 頁面排序 拖曳調整。每個步驟都產生新檔案，原檔保留不變。

事務機或掃描 App 產生的 PDF，常見問題就是多出空白頁、有幾頁倒過來、背面順序顛倒。以下說明每個步驟的做法和要注意的地方。

開啟「刪除 PDF 頁面」工具

整理掃描 PDF 的 4 個步驟

  1. 開啟「刪除 PDF 頁面」並選擇掃描檔，按「自動標記空白頁」。系統會逐頁檢查幾乎全白的頁面並標記，請看過縮圖確認，誤判的按 ↩ 還原，再按「套用並下載 PDF」。
  2. 用「PDF 旋轉」打開剛才下載的檔案，在方向不對的頁面按 ↺ 或 ↻；整份上下顛倒時按兩次「全部向右轉」，然後套用並下載。
  3. 若順序有誤，用「PDF 頁面排序」拖曳縮圖調整；雙面掃描背面倒序時，可以先用「反轉順序」再微調。
  4. 最後依用途拆分或合併：只要寄其中幾頁就用「PDF 分割」擷取；要和其他文件合成一份就用「PDF 合併」。

用手機也能整理嗎？

可以，所有工具在手機瀏覽器都能用，縮圖會以多欄顯示，點 🗑、↺、↻ 即可操作。不過掃描檔頁數多、每頁又是大圖時，手機記憶體可能吃緊，處理會比較慢；頁數很多的掃描檔建議在電腦上整理。每一步下載的新檔案會存在「下載」資料夾或「檔案」App 的「下載項目」，下一步記得選最新的那個檔案。

空白頁偵測的判斷方式與限制

系統會把每一頁縮小繪製，計算非白色像素的比例，幾乎全白的頁面才會被標記。紙張淡淡的紋路通常仍會判為空白；但背面透出正面字跡、有頁碼或頁首的頁面，可能不會被標記。自動偵測只是幫您先勾選，下載前一定要看過一次。詳細操作可參考 怎麼刪除 PDF 頁面。

旋轉要儲存才算數

很多閱讀器的旋轉只改變當下的檢視方向，關掉再開又回到原樣。本站的 PDF 旋轉會把方向寫進檔案，說明見 PDF 旋轉後怎麼儲存。

本站做不到的事

  • 沒有文字辨識（OCR），掃描檔裡的字仍然是圖片，無法搜尋或複製。
  • 沒有壓縮功能，掃描檔整理後大小不會明顯變小。
  • 無法去除陰影、調整亮度或自動裁切歪斜，這些需要在掃描時或用影像軟體處理。

常見問題

檔案會上傳到伺服器嗎？

不會。偵測空白頁、刪除、旋轉與排序都是由您手機或電腦上的瀏覽器執行，本站是放在 GitHub Pages 的靜態網頁，沒有接收檔案的伺服器。網頁的內容安全政策（CSP）也限制只能連線到本站，您可以用電腦瀏覽器的開發者工具，在「網路」分頁確認處理過程沒有上傳請求。

檔案大小有限制嗎？

本站的程式沒有設定檔案大小或數量的上限。實際能處理多大的檔案，取決於您裝置的記憶體與瀏覽器；手機的記憶體通常比電腦少，檔案很大時可能會比較慢，甚至處理失敗，這時可以改用電腦，或把檔案分批處理。

需要註冊或付費嗎？

不需要。打開網頁就能用，不需要帳號、Email，也不用安裝 App；工具免費使用，本站沒有設定每天的使用次數限制。

一定要分成好幾個工具做嗎？

不一定。「PDF 旋轉」與「PDF 頁面排序」的縮圖下方也有 🗑 刪除，所以少量刪頁、旋轉、排序可以在同一個畫面完成。只有「自動標記空白頁」是「刪除 PDF 頁面」才有的功能。

整理到一半想重來怎麼辦？

每一步都是另外產生新檔案，原始掃描檔一直保留在您的裝置上。只要重新選擇原始檔案，就可以從頭開始處理；建議每一步下載後就檢查一次，比較容易找出是哪一步出錯。

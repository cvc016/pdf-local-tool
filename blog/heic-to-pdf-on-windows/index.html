HEIC 照片轉 PDF 打不開？iPhone、Mac、Windows 的做法

直接回答：在 iPhone、iPad 或 Mac 上用 Safari 開啟「HEIC 轉 PDF」，選取 HEIC 照片、排好順序，按「轉換成 PDF 並下載」即可。本工具為了不上傳檔案，是用瀏覽器內建的影像解碼讀取 HEIC，所以瀏覽器本身要支援 HEIC；在 Windows 或多數 Chrome 上可能會顯示「此瀏覽器無法讀取 HEIC，請改用 Safari，或先轉成 JPG」，這時請改用下面的替代方法。

HEIC 是 iPhone 預設的照片格式，畫質好、檔案小，但不少電腦和網站無法直接開啟，所以要繳交文件時常需要轉成 PDF 或 JPG。

開啟「HEIC 轉 PDF」工具

HEIC 轉 PDF 的 4 個步驟

  1. 在 iPhone、iPad 或 Mac 用 Safari 開啟「HEIC 轉 PDF」。
  2. 點上方區域選取 HEIC 照片，可以一次選多張，也能和 JPG、PNG 混合。
  3. 用 ▲▼ 或 ⠿ 調整順序，選擇紙張大小、方向與邊界。
  4. 按「轉換成 PDF 並下載」，到「檔案」App 的「下載項目」（Mac 為「下載項目」資料夾）開啟確認。

iPhone 上的小提醒

從「照片圖庫」選取時，iPhone 在某些情況下會先把 HEIC 轉成 JPG 再交給網頁，是否轉換視相機格式與分享方式而定，這不影響結果。若之後經常需要和 Windows 電腦交換照片，可以到「設定 > 相機 > 格式」選「最相容」，之後拍的照片就會是 JPG（已拍的照片不會改變）。Android 手機的瀏覽器多半無法讀取 HEIC。

Windows 電腦讀不了 HEIC 怎麼辦？

  • 從 iPhone 直接轉：照片還在 iPhone 上時，直接在 iPhone 的 Safari 完成轉換，再把 PDF 傳到電腦，通常最省事。
  • 先轉成 JPG：在 Mac 可以用「預覽程式」把照片輸出成 JPG；轉好後用 圖片轉 PDF 製作 PDF。
  • 改變拍攝格式：如上所述把 iPhone 相機格式改成「最相容」。

如果照片已經透過雲端或傳輸線放到 Windows 電腦，而您手邊也有 iPhone，可以先把照片傳回 iPhone 或改用 Mac 處理；或者在上傳照片到電腦前，就先在 iPhone 上轉成 PDF，之後只需要傳一個檔案，比較不容易遺漏。

本站不會為了支援 HEIC 而把照片送到伺服器轉換，這是刻意的取捨：多一點限制，換來照片不離開您的裝置。

轉換後的檔案與畫質

每張照片會成為 PDF 的一頁，並依拍攝方向自動轉正。若仍有頁面方向不對，可用 PDF 旋轉 調整，參考 PDF 旋轉後怎麼儲存。iPhone 照片轉 PDF 的完整流程與檔案大小說明，可以看 iPhone 照片轉 PDF 教學。

常見問題

檔案會上傳到伺服器嗎？

不會。HEIC 解碼與 PDF 產生都是由您手機或電腦上的瀏覽器執行，本站是放在 GitHub Pages 的靜態網頁，沒有接收檔案的伺服器。網頁的內容安全政策（CSP）也限制只能連線到本站，您可以用電腦瀏覽器的開發者工具，在「網路」分頁確認處理過程沒有上傳請求。

檔案大小有限制嗎？

本站的程式沒有設定檔案大小或數量的上限。能轉換幾張照片、實際能處理多大的檔案，取決於您裝置的記憶體與瀏覽器；手機的記憶體通常比電腦少，檔案很大時可能會比較慢，甚至處理失敗，這時可以改用電腦，或把檔案分批處理。

需要註冊或付費嗎？

不需要。打開網頁就能用，不需要帳號、Email，也不用安裝 App；工具免費使用，本站沒有設定每天的使用次數限制。

為什麼 Chrome 不能用？

HEIC 的解碼依賴瀏覽器與作業系統的支援，目前多數 Windows 與 Android 上的瀏覽器無法在網頁中讀取 HEIC。本站不上傳檔案，因此無法改由伺服器代為轉換。

安全嗎？會不會被別人看到？

檔案只會被讀進您裝置的記憶體，處理結果直接下載到您的裝置，本站無法取得檔案內容。本站不使用 Cookie、不做追蹤分析，也不載入第三方腳本。要注意的是裝置本身的安全：在公用電腦或借來的手機上使用時，處理完記得把下載的檔案刪除。

HEIC 可以和 JPG 放在同一份 PDF 嗎？

可以。選取時可以混合 HEIC、JPG、PNG 等圖片，清單排好順序後會一起轉成同一份 PDF，每張圖片各占一頁。

轉出來的 PDF 檔案很大怎麼辦？

每張照片會以原始解析度放進 PDF，張數多時檔案會比較大。本站目前沒有壓縮功能，可以減少張數、先在相簿裁切照片，或把照片分成幾份 PDF。

iPad 也可以用嗎？

可以。iPad 的 Safari 與 iPhone 一樣能讀取 HEIC，操作步驟相同，下載的檔案在「檔案」App 的「下載項目」。

線上合併 PDF 會不會上傳檔案？隱私與自我檢查方法

直接回答：要看工具的做法。很多線上 PDF 服務會先把檔案上傳到它們的伺服器處理，再讓您下載結果；Waiting Studio 本機 PDF 的「PDF 合併」則是把處理程式下載到您的瀏覽器，在您的手機或電腦上直接合併，檔案不會傳到任何伺服器。不論用哪個工具，比起只看廣告文字，最可靠的方法是自己檢查網路連線，下面會教您怎麼看。

需要合併的常常是合約、身分證影本、薪資單、病歷這類敏感資料，花幾分鐘確認一下是值得的。

開啟「PDF 合併」工具

自己確認合併 PDF 有沒有上傳的 4 個步驟（電腦）

  1. 在電腦用 Chrome、Edge 或 Firefox 開啟「PDF 合併」頁面，按 F12（Mac 為 Option + Command + I）開啟開發者工具，切換到「網路」（Network）分頁。
  2. 先按清除按鈕把清單清空，接著選取要合併的 PDF，並按「合併 PDF 並下載」。
  3. 觀察網路分頁：若有上傳，通常會看到大小接近您的檔案、方法為 POST 或 PUT 的請求送到其他網址。本站處理過程中不應出現這類請求。
  4. 想更確定，可以先把 PDF 加入清單（讓瀏覽器把處理程式下載好、清單顯示出頁數），接著把電腦的網路關掉（例如關閉 Wi-Fi），再按合併；若仍能完成並下載，代表處理是在本機進行。

手機上怎麼判斷？

手機瀏覽器通常沒有開發者工具，比較簡單的方法是：先開啟工具頁並把 PDF 加入清單，等清單顯示出頁數（代表處理程式已載入），再開啟飛航模式並按合併。若工具需要上傳，離線時就會失敗；本站的合併在這種情況下仍能完成並下載。檢查完記得關閉飛航模式。手機實際操作步驟可參考 手機 PDF 合併教學。

本站為什麼不需要上傳

本站是放在 GitHub Pages 的靜態網頁，沒有接收檔案的後端伺服器。合併時使用開源函式庫 pdf-lib，在瀏覽器裡讀取每個 PDF、複製頁面、組合成新檔案，再交給瀏覽器下載。網頁的內容安全政策（CSP）限制只能連線到本站本身，本站不使用 Cookie、不做追蹤分析、不載入第三方腳本。原始碼公開在 GitHub，有興趣可以自行檢視。

本機處理的限制

誠實地說，本機處理也有缺點：速度與能處理的大小取決於您的裝置，手機記憶體較少，檔案很大時可能較慢或失敗；有密碼保護或已加密的 PDF 目前不支援。另外，檔案不上傳只代表本站拿不到檔案，下載後的檔案存在您的裝置上，在公用電腦使用完請記得刪除。

其他工具也一樣不上傳

本站的 PDF 分割、刪除 PDF 頁面、PDF 旋轉、圖片轉 PDF 都採用同樣的本機處理方式，可以用相同方法自行檢查。

常見問題

安全嗎？會不會被別人看到？

檔案只會被讀進您裝置的記憶體，處理結果直接下載到您的裝置，本站無法取得檔案內容。本站不使用 Cookie、不做追蹤分析，也不載入第三方腳本。要注意的是裝置本身的安全：在公用電腦或借來的手機上使用時，處理完記得把下載的檔案刪除。

檔案大小有限制嗎？

本站的程式沒有設定檔案大小或數量的上限。能合併幾個檔案、實際能處理多大的檔案，取決於您裝置的記憶體與瀏覽器；手機的記憶體通常比電腦少，檔案很大時可能會比較慢，甚至處理失敗，這時可以改用電腦，或把檔案分批處理。

需要註冊或付費嗎？

不需要。打開網頁就能用，不需要帳號、Email，也不用安裝 App；工具免費使用，本站沒有設定每天的使用次數限制。

開發者工具裡看到一些請求，是上傳嗎？

開啟頁面時，瀏覽器會向本站下載網頁、樣式與處理 PDF 用的程式碼，這些是下載而不是上傳。判斷上傳可以看請求方法（POST、PUT）與送出的資料大小，以及目的地是不是其他網站。

為什麼還是建議自己檢查？

任何網站都可以宣稱不上傳，自己用網路分頁或離線測試確認，是不必相信任何人說法的方法，對其他工具也適用。

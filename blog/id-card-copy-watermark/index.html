身分證影本加浮水印：寫法範例與免安裝教學

發布：2026-11-03　作者：Waiting Studio

浮水印要寫清楚用途、對象與日期，例如「僅供 ○○ 電信門號申辦使用 2026/11/03」，並且斜向平鋪整張證件、壓過姓名與證號。開啟「圖片加浮水印」，選取證件照片、輸入文字、位置選「斜向平鋪」，不透明度約 35%，按「加上浮水印並下載」即可。整個過程在瀏覽器本機完成，證件照片不會上傳到任何伺服器。

辦門號、租屋、申請貸款、報名課程或網路賣家實名認證，常被要求傳身分證正反面照片。這些影像一旦外流，可能被拿去冒名申辦、註冊帳號或詐騙。加上浮水印不能百分之百防止濫用，但能清楚標示這份影本的唯一用途，讓別人很難把它挪用到其他地方，也是金融機構與政府單位常建議的做法。

開啟「圖片加浮水印」工具

幫身分證影本加浮水印的 4 個步驟

  1. 開啟「圖片加浮水印」頁面，點選虛線區域或把證件照片拖曳進來；正反面可以一次選取，會套用相同的浮水印。
  2. 在「浮水印文字」輸入用途、對象與日期，例如「僅供 ○○ 銀行開戶使用」，按 Enter 可以換行再加上日期。
  3. 位置選「斜向平鋪（證件建議）」，大小約 5～8%，不透明度 30～45%，顏色可用灰色或紅色；清單縮圖會即時更新，可以放大檢查。
  4. 按「加上浮水印並下載」：單張直接下載，多張打包成「浮水印圖片.zip」，再把下載的檔案傳給對方。

用手機幫證件照片加浮水印

多數人是用手機拍證件、用手機傳送，因此直接在手機上處理最方便。iPhone 用 Safari 開啟圖片加浮水印頁面，點選上方區域後可選「照片圖庫」挑選已拍好的照片，或選「拍照」直接拍攝。輸入文字時可以用語音輸入。完成後檔案會存到「檔案」App 的「下載項目」，點開後按分享即可傳到 LINE、Email 或存回「照片」。

Android 用 Chrome 開啟，從相簿選取照片，完成的檔案在「下載」資料夾。不需要安裝任何修圖 App，也不必擔心 App 要求讀取整個相簿的權限。

浮水印文字範例

  • 僅供 ○○ 電信門號申辦使用 2026/11/03
  • 僅供 ○○ 銀行貸款申請使用，他用無效
  • 僅供 ○○ 路○號租屋簽約使用
  • 僅供 ○○ 協會報名身分確認，限本次活動

重點是讓看到影本的人一眼知道「這份資料只能用在哪裡」。寫上日期可以避免同一份影本日後被重複使用；寫上對象可以讓其他單位一看就知道這不是給他們的資料。文字不必太長，兩行以內最清楚。

為什麼要斜向平鋪，而不是放在角落？

放在角落的浮水印很容易被裁切掉，或用修圖軟體一筆擦除。斜向平鋪會讓文字重複覆蓋整張證件，包含姓名、身分證字號、出生日期與照片等關鍵欄位，要去除就必須重繪大部分內容，難度高很多。本工具的浮水印是直接畫進圖片像素，不是另外一層可以隱藏的圖層。不透明度不要調得太高，否則對方審核時看不清楚證件內容，反而可能被要求重傳；大約 30～45% 是兼顧辨識與防護的範圍。

為什麼不要用會上傳照片的線上工具？

很多加浮水印的網站或 App，需要先把照片上傳到他們的伺服器處理。身分證照片是高度敏感的個人資料，上傳到不熟悉的服務，本身就是一種外流風險。本站是放在 GitHub Pages 的靜態網頁，浮水印是由您裝置上的瀏覽器在畫布上繪製，網頁的內容安全政策只允許連線到本站，處理過程沒有任何上傳請求，您可以用電腦瀏覽器的開發者工具在「網路」分頁自行確認。處理後的圖片也不會保留 EXIF 資訊（拍攝地點、手機型號），分享時更安全。

傳送前的檢查清單

傳出去之前，請放大檢查三件事：證件上的文字仍然清晰可讀、浮水印有壓到姓名與證號、用途與日期寫的是正確的對象。原始未加浮水印的照片請保存在自己的裝置，不要放在共用相簿或雲端分享資料夾。若對方要求 PDF，可以把加好浮水印的正反面用 JPG 轉 PDF 合成一份；檔案太大被系統拒收，可先用 圖片壓縮 縮小，或用 圖片尺寸調整 把最長邊改成 1920 px。整理申請文件的完整流程，也可以參考 報帳與申請文件的 PDF 整理清單。

常見問題

健保卡、駕照、存摺封面也能用嗎？

可以。任何證件或文件的照片、截圖都能加上文字浮水印，做法相同。

對方說浮水印太深看不清楚怎麼辦？

把不透明度降到 25～30%，或把字的大小調小一點，重新下載即可；原圖不會被修改。

強密碼怎麼設？一次搞懂長度、字元與密碼管理

發布：2026-11-03　作者：Waiting Studio

強密碼的關鍵是夠長、完全隨機、每個網站都不同。一般帳號建議至少 16 個字元，混合大小寫、數字與符號；重要帳號再開啟兩步驟驗證。開啟「隨機密碼產生器」，長度選 16 以上、勾選四種字元，按「複製」貼到註冊頁，並存進密碼管理器即可。密碼由您裝置上的瀏覽器產生，不會傳到任何伺服器。

很多人以為把生日換成「P@ssw0rd」這種替換就算複雜，其實這類規則早就被破解工具內建。真正讓密碼難以猜中的，是亂數與長度；而真正讓帳號安全的，是不要在不同網站重複使用同一組密碼。

開啟「隨機密碼產生器」工具

用隨機密碼產生器做出強密碼的 4 個步驟

  1. 開啟「隨機密碼產生器」頁面，把長度滑桿拉到 16～20 個字元。
  2. 勾選大寫、小寫、數字與符號；如果之後需要手動輸入（例如電視或遊戲機），可勾選「排除容易混淆的字元」。
  3. 確認下方顯示的強度為「強」或「非常強」，不滿意就按「重新產生」。
  4. 按密碼旁的「複製」，貼到網站的新密碼欄位，並立刻存進密碼管理器，不要另外寫在便利貼上。

在手機上產生並保存密碼

iPhone 用 Safari 開啟隨機密碼產生器，調好長度後點「複製」，切換到 App 的註冊畫面貼上；iOS 會詢問是否存到 iCloud 鑰匙圈，選擇儲存即可，之後在同一個 Apple 帳號的裝置上都能自動填入。Android 用 Chrome 開啟，貼上後 Google 密碼管理工具同樣會提示儲存。

如果網站限制密碼長度或不允許某些符號，可以先取消勾選「符號」，再把長度加長來維持強度。產生的密碼只存在當下的頁面中，重新整理就會消失，所以請在關閉頁面前確認已經保存。

密碼強度是怎麼計算的？

密碼的強度通常用「位元熵」表示：長度乘上每個字元可能的種類數取對數。只用小寫英文字母時，每個字元約 4.7 位元；加上大寫與數字約 6 位元；再加上符號約 6.5 位元。所以 8 個字元的全種類密碼大約 52 位元，16 個字元則超過 100 位元。每多 1 位元，可能的組合就多一倍，攻擊者需要嘗試的次數也跟著加倍。這也說明了為什麼「加長」比「加一個驚嘆號」有效得多：多 4 個字元帶來的強度，遠超過把一個字母換成符號。

不過這個計算只適用於真正隨機的密碼。人自己想的密碼，常常是單字、名字、生日、鍵盤順序（qwerty、1qaz2wsx）或常見替換，破解工具會優先嘗試這些模式，實際強度比字面上低很多。這就是為什麼建議交給程式用安全亂數產生，而不是自己編。

最常見的 5 個密碼錯誤

  • 所有網站用同一組密碼：一個網站外洩，其他帳號全部危險，這種攻擊稱為「撞庫」。
  • 只在舊密碼後面加數字：例如 abc123 改成 abc124，被猜中的機率非常高。
  • 使用個人資料：生日、電話、身分證字號、寵物名字，都很容易從社群網站找到。
  • 把密碼存在手機備忘錄或截圖：手機遺失或相簿同步到雲端時就可能外流。
  • 不開兩步驟驗證：即使密碼被盜，兩步驟驗證也能擋下大部分的入侵。

記不住怎麼辦？用密碼管理器

每個網站都使用不同的 16 位隨機密碼，沒有人記得住，這正是密碼管理器存在的理由。iCloud 鑰匙圈、Google 密碼管理工具、Bitwarden、1Password 等都能加密保存密碼並自動填入，您只需要記住一組夠強的主密碼。主密碼可以使用由多個隨機單字組成的長句，方便記憶又足夠長。電子郵件信箱的密碼尤其重要，因為其他帳號的「忘記密碼」都會寄到信箱，請務必設定獨一無二的強密碼並開啟兩步驟驗證。

為什麼本站的產生器可以放心使用？

有些線上密碼產生器是在伺服器端產生密碼再傳回瀏覽器，理論上對方可以記錄下來。本站的隨機密碼產生器是放在 GitHub Pages 的靜態網頁，密碼完全由您瀏覽器內建的 Web Crypto 安全亂數產生，並使用拒絕取樣避免某些字元機率偏高；網頁的內容安全政策只允許連線到本站，產生過程沒有任何網路請求，可以在開發者工具的「網路」分頁自行確認。想把店裡的 Wi-Fi 密碼分享給客人，可以搭配 QR Code 產生器 做成掃描就能連線的 QR Code，做法可參考 店家 Wi-Fi QR Code 製作教學。

常見問題

產生的密碼會被記錄或上傳嗎？

不會。密碼由您瀏覽器中的程式用安全亂數產生，沒有傳到任何伺服器，本站也不儲存；重新整理頁面就會消失。

密碼一定要有符號嗎？

不一定。符號能增加強度，但把長度加長效果更好；網站不接受符號時，用 20 個字元的大小寫加數字同樣非常安全。

多久要換一次密碼？

現在的建議是不必定期更換，而是在網站外洩、懷疑被盜或曾與他人共用時立即更換，並確保每個網站密碼都不同。

履歷轉 PDF 檔案太大怎麼辦？上傳人力銀行前的實用檢查

直接回答：履歷 PDF 太大，最常見的原因是放了解析度很高的照片，或是把整份履歷「拍照／掃描」成圖片再轉 PDF。最有效的做法是回到 Word、Google 文件等原始檔，直接「另存為 PDF」，讓文字保持文字；若一定要用照片，先把照片縮小再轉。要先說清楚：Waiting Studio 本機 PDF 目前沒有 PDF 壓縮功能，無法把現有的 PDF 直接變小，下面會說明本站工具能幫上忙的部分。

投遞履歷時，人力銀行或企業的應徵系統常會限制附件大小，超過就上傳失敗。各平台的上限不同，而且可能調整，請以您要上傳的網站說明為準。

開啟「圖片轉 PDF」工具

把履歷 PDF 變小的 4 個檢查步驟

  1. 先看檔案大小與來源：如果履歷是用 Word 或 Google 文件寫的，直接用該軟體的「另存為 PDF」或「下載為 PDF」重新匯出，文字型 PDF 通常比拍照轉成的 PDF 小很多。
  2. 檢查大頭照與作品圖：在原始檔裡把照片換成較小的版本（例如先用手機相簿的編輯功能裁切），再重新匯出 PDF。
  3. 如果履歷只有照片或掃描圖，可以用「圖片轉 PDF」把圖片組成 PDF；這個工具會直接使用原始 JPG 資料、不重新壓縮，所以 PDF 大小約等於照片相加，請先把照片縮小再轉。
  4. 刪掉不需要的頁面：作品集、證照影本若不是必要，可以用「刪除 PDF 頁面」移除，或另外做成一份附件，再確認大小是否符合上傳限制。

在手機上整理履歷要注意什麼

用手機拍紙本履歷再轉 PDF，是檔案變大的常見原因：手機相機的解析度很高，一張照片就可能好幾 MB。若只能用手機，可以先在相簿裡裁切掉桌面等多餘部分；部分手機相機也能調整拍攝解析度，請依您的機型設定為準。iPhone 若拍成 HEIC 格式，可以參考 iPhone 照片轉 PDF 教學。

轉好之後，在「檔案」App 或檔案管理裡查看檔案資訊，就能看到大小，上傳前先確認一次。

為什麼履歷 PDF 會這麼大？

  • 整份都是圖片：拍照或掃描產生的 PDF，每一頁其實是一張圖，文字無法選取，檔案也大。
  • 照片原圖直接放入：大頭照、作品截圖沒有縮小就插入文件。
  • 頁數太多：把證照、成績單、作品集全部合在同一份。

本站能做與不能做的事

Waiting Studio 本機 PDF 的工具都在瀏覽器本機執行，檔案不上傳，適合處理含有個人資料的履歷。目前可以做到：把照片轉成 PDF（圖片轉 PDF）、刪除多餘頁面（刪除 PDF 頁面）、把履歷與附件合成一份（PDF 合併）。但是沒有壓縮 PDF、降低圖片解析度的功能，合併、分割、旋轉時也都會保留原本的畫質，所以不會讓檔案變小。若真的需要壓縮，請使用您信任的軟體，並留意履歷含有個人資料，上傳到不明網站前要多想一下。

拆成兩份也是一種做法

如果平台允許上傳多個附件，可以把「履歷本文」與「作品集／證照」分開。用 PDF 分割 依頁碼範圍拆成兩個檔案，每份都比較小，面試官閱讀時也比較清楚。

常見問題

檔案會上傳到伺服器嗎？

不會。轉換、刪頁與合併都是由您手機或電腦上的瀏覽器執行，本站是放在 GitHub Pages 的靜態網頁，沒有接收檔案的伺服器。網頁的內容安全政策（CSP）也限制只能連線到本站，您可以用電腦瀏覽器的開發者工具，在「網路」分頁確認處理過程沒有上傳請求。

需要註冊或付費嗎？

不需要。打開網頁就能用，不需要帳號、Email，也不用安裝 App；工具免費使用，本站沒有設定每天的使用次數限制。

本站有 PDF 壓縮功能嗎？

目前沒有。本站的工具都會保留原始畫質，不會讓檔案變小。若之後推出壓縮功能，會在首頁與工具清單中標示；在那之前，建議從原始檔重新匯出，或先縮小照片再轉 PDF。

人力銀行的檔案上限是多少？

各平台不同，也可能隨時調整，本文不列出特定數字，請以您上傳時網站顯示的說明為準。

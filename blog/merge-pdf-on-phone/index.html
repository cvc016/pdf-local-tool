手機 PDF 合併怎麼做？iPhone、Android 不裝 App 也能合併

直接回答：用手機瀏覽器開啟 本機PDF 的「PDF 合併」頁面，選取兩個以上的 PDF 檔案，用 ▲▼ 按鈕（或按住 ⠿ 拖曳）排好順序，再按「合併 PDF 並下載」，就會得到一個合併好的 PDF。整個過程不用安裝 App、不用註冊，檔案是在手機的瀏覽器裡處理，不會上傳到伺服器。

很多人在手機上收到好幾份 PDF，例如報名表、身分證影本、繳費證明，想合成一個檔案再寄出去，卻發現手機內建功能找不到「合併」，下載 App 又擔心要註冊、要付費，或要把檔案上傳到不認識的伺服器。下面用實際的按鈕名稱，一步一步說明在手機上怎麼做。

開啟「PDF 合併」工具

手機合併 PDF 的 4 個步驟

  1. 用手機瀏覽器開啟「PDF 合併」頁面，點一下「選擇或拖放 PDF 檔案」的虛線區域，從手機裡挑選要合併的 PDF。如果選擇畫面一次只能選一個檔案也沒關係，之後可以用「加入更多 PDF」繼續加入。
  2. 確認檔案清單：每個檔案會顯示檔名、檔案大小與頁數，清單上方會顯示「N 個檔案，共 X 頁」。清單裡至少要有 2 個檔案，「合併 PDF 並下載」按鈕才能按。
  3. 調整順序：按 ▲ 或 ▼ 把檔案往上或往下移，也可以按住左側的 ⠿ 拖曳；合併時會由上到下依序排列。不需要的檔案按 ✕ 移除，想重來可以按「全部清除」。
  4. 按「合併 PDF 並下載」。完成後畫面會顯示「✓ 完成！」以及合併的檔案數、總頁數和檔案大小，新檔案的檔名是第一個檔案的名稱加上「_合併」。

iPhone、Android 實際操作的注意事項

iPhone（Safari）

建議用 Safari 開啟工具頁。點選上傳區域後，iPhone 會跳出選取檔案的畫面，通常可以從「檔案」App 裡的「iCloud 雲碟」或「我的 iPhone」挑選 PDF。如果 PDF 是在 LINE、郵件或其他 App 裡收到的，請先用該 App 的分享功能，把檔案存到「檔案」App，再回到網頁選取。

手機上調整順序時，用 ▲▼ 按鈕最穩定；若想用拖曳，請按住每一列左側的 ⠿ 圖示再移動，直接拖曳檔名的地方會變成捲動畫面。拖到畫面上緣或下緣時，頁面會自動捲動。

按下「合併 PDF 並下載」後，Safari 會開始下載檔案。依照您的 Safari 設定，下載的檔案通常會存到「檔案」App 的「下載項目」資料夾；如果找不到，可以點 Safari 網址列附近的下載圖示查看。各版本 iOS 的畫面文字可能略有不同，以您手機上看到的為準。

Android（Chrome）

Android 手機用 Chrome 開啟工具頁，點選上傳區域後，可以從手機的檔案管理或雲端硬碟挑選 PDF。操作方式和 iPhone 相同，合併後的檔案一般會存到「下載」資料夾，也可以從 Chrome 的下載清單開啟。

合併前可以先整理好每個檔案

PDF 合併只會把每個檔案的「全部頁面」依序接在一起，不會自動刪頁或轉向。如果其中一份只需要幾頁，可以先用 PDF 分割 擷取需要的頁面；有頁面方向不對，可以先用 PDF 旋轉 轉正；合併後才發現多了不要的頁面，再用 刪除 PDF 頁面 移除，或用 PDF 頁面排序 微調頁面順序。這些工具都和合併一樣，在瀏覽器裡處理，不會上傳檔案。

合併後畫質會變差嗎？

不會。合併時，程式是用開源函式庫 pdf-lib 把每個檔案的頁面複製到新的 PDF，原本的文字、圖片和向量圖形都直接沿用，不會重新壓縮或轉成圖片，所以文字仍然可以選取、搜尋。也因為不壓縮，合併後的檔案大小通常和各個檔案相加差不多，不會明顯變小。

哪些 PDF 無法合併？

有密碼保護或已加密的 PDF 目前不支援。這類檔案加入清單時，可能會顯示「無法讀取（可能已加密或損毀）」，按下合併時也會出現「有密碼保護或已加密，目前不支援」的提示。請先用原本的軟體移除密碼，或請對方提供沒有加密的版本。檔案損毀或其實不是 PDF 的檔案，同樣無法合併，建議先按 ✕ 把它從清單移除。

另外，合併工具只接受 PDF。想把手機拍的照片或截圖合成 PDF，請改用 圖片轉 PDF，詳細做法可以參考 iPhone 照片轉 PDF 教學。

為什麼手機合併 PDF 不必上傳？

一般的線上 PDF 工具，會先把檔案上傳到對方的伺服器，處理完再讓您下載。本機PDF 的做法不同：整個網站是一組靜態網頁，打開頁面時瀏覽器會下載處理 PDF 所需的程式碼，之後讀取檔案、複製頁面、產生新檔案，都由手機上的瀏覽器直接完成，結果再透過「下載」存到手機裡。處理合約、證件影本這類資料時，檔案不必離開自己的裝置，比較安心。

常見問題

檔案會上傳到伺服器嗎？

不會。讀取檔案、複製頁面與產生合併後的 PDF都是由您手機或電腦上的瀏覽器執行，本站是放在 GitHub Pages 的靜態網頁，沒有接收檔案的伺服器。網頁的內容安全政策（CSP）也限制只能連線到本站，您可以用電腦瀏覽器的開發者工具，在「網路」分頁確認處理過程沒有上傳請求。

安全嗎？會不會被別人看到？

檔案只會被讀進您裝置的記憶體，處理結果直接下載到您的裝置，本站無法取得檔案內容。本站不使用 Cookie、不做追蹤分析，也不載入第三方腳本。要注意的是裝置本身的安全：在公用電腦或借來的手機上使用時，處理完記得把下載的檔案刪除。

檔案大小有限制嗎？

本站的程式沒有設定檔案大小或數量的上限。能合併幾個檔案、實際能處理多大的檔案，取決於您裝置的記憶體與瀏覽器；手機的記憶體通常比電腦少，檔案很大時可能會比較慢，甚至處理失敗，這時可以改用電腦，或把檔案分批處理。

需要註冊或付費嗎？

不需要。打開網頁就能用，不需要帳號、Email，也不用安裝 App；工具免費使用，本站沒有設定每天的使用次數限制。

一次只能選一個檔案怎麼辦？

先選一個 PDF，接著按清單下方的「加入更多 PDF」，再選下一個，重複到全部加入為止。加入後一樣可以用 ▲▼ 調整順序。

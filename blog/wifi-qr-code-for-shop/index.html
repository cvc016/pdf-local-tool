Wi-Fi QR Code 怎麼做？掃一下就連上網

直接回答：開啟「QR Code 產生器」，內容類型選「Wi-Fi」，輸入網路名稱（SSID）與密碼，加密方式一般選「WPA／WPA2／WPA3」，再下載 PNG 印出來即可。iPhone（iOS 11 以上）與大多數 Android 手機用內建相機掃描，就會跳出「加入網路」的提示。整個過程在瀏覽器本機完成，Wi-Fi 密碼不會傳到任何伺服器。

咖啡店、民宿、診所等候區、辦公室會議室，最常被問的就是「Wi-Fi 密碼是多少」。密碼一長、大小寫一混，念給客人聽常常輸錯好幾次。把 Wi-Fi 資訊做成 QR Code 貼在桌上或櫃台，客人掃一下就能連線。

開啟「QR Code 產生器」工具

製作 Wi-Fi QR Code 的 4 個步驟

  1. 開啟「QR Code 產生器」，內容類型選「Wi-Fi」。
  2. 輸入網路名稱（SSID）與密碼，大小寫與空格都要和路由器設定完全一致。
  3. 選擇加密方式：近年的路由器幾乎都是 WPA／WPA2／WPA3；開放網路選「無密碼」。如果網路設為隱藏（不廣播名稱），請勾選「隱藏的網路」。
  4. 按「下載 PNG」，印刷前先用 iPhone 與 Android 各掃一次，確認能直接連上。

客人怎麼掃描連線？

iPhone：打開內建「相機」對準 QR Code，畫面上方會出現「加入『網路名稱』網路」，點一下即可。Android：多數手機可用相機或 Google 智慧鏡頭掃描，出現「連線」按鈕後點選；部分機型也可以在「設定 > Wi-Fi」右上角的掃描圖示掃描。LINE 內建的掃描器只會顯示文字，不會自動連線，建議請客人用相機掃。

Wi-Fi QR Code 裡面存了什麼？

Wi-Fi QR Code 使用通用的格式，例如 WIFI:T:WPA;S:網路名稱;P:密碼;;。手機相機讀到這段文字，就知道要連哪個網路、用什麼密碼。名稱或密碼中如果有分號、逗號、冒號等特殊符號，本工具會自動加上跳脫字元，避免手機讀錯。展開工具下方的「QR Code 內容」可以看到實際編碼的文字。

安全注意事項

  • 給客人用訪客網路：QR Code 等於公開密碼，建議在路由器開一個「訪客網路」，和店內收銀、監視器等設備分開。
  • 改密碼後要重做：靜態 QR Code 內容無法修改，更換 Wi-Fi 密碼後請重新產生並替換印好的 QR Code。
  • 不要用來路不明的線上產生器：有些網站會把您輸入的內容送到伺服器；本工具在瀏覽器中產生，密碼不會離開您的裝置。

擺放與印刷建議

桌卡或櫃台立牌上，QR Code 印 3～5 公分見方就很好掃；貼在牆上要讓客人遠一點也能掃，可以放大到 8 公分以上。旁邊寫上「掃描連線 Wi-Fi」與網路名稱，並保留文字版密碼，方便舊手機或筆電手動輸入。想加上店家 Logo 也可以，但印出後一定要實測。若要做成多頁的店內說明 PDF，可以把 QR Code 圖片用 JPG 轉 PDF 合成。

加密方式選錯會怎樣？

手機會依照 QR Code 裡的加密方式嘗試連線，選錯時可能顯示「無法加入網路」或一直要求重新輸入密碼。近十年的家用與商用路由器，預設幾乎都是 WPA2 或 WPA3，選「WPA／WPA2／WPA3」即可；只有非常舊的設備才會用 WEP，而 WEP 已不安全，建議直接在路由器改用 WPA2 以上。若您不確定，可以登入路由器管理頁面，在無線網路設定中查看「安全性」或「驗證方式」欄位。

辦公室與民宿的小技巧

民宿可以把 Wi-Fi QR Code 和入住須知放在同一張卡片上，並在背面寫上退房時間與緊急聯絡電話；辦公室會議室則可以貼在投影機旁，讓來訪的客戶自行連線，不必每次請同事幫忙輸入密碼。定期更換訪客網路密碼時，記得同步更新 QR Code，並把舊的卡片回收，避免過期的 QR Code 讓客人連不上而以為網路故障。

常見問題

Wi-Fi 密碼會上傳嗎？

不會。QR Code 在您的瀏覽器中產生，本站沒有接收資料的伺服器，Wi-Fi 名稱與密碼都不會傳出您的裝置。

需要註冊或付費嗎？

不需要。打開網頁就能用，不需要帳號、Email，也不用安裝 App；工具免費使用，本站沒有設定每天的使用次數限制。

掃描後沒有跳出連線提示？

請確認手機系統夠新（iPhone 需 iOS 11 以上），並使用內建相機而不是 LINE 掃描。若仍無法連線，檢查名稱與密碼的大小寫、加密方式是否和路由器一致。

5GHz 和 2.4GHz 名稱不同怎麼辦？

每個 QR Code 只能存一組網路名稱。兩個頻段名稱不同時，可以各做一個，或在路由器把兩者設成同一個名稱。

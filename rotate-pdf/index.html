PDF 旋轉

旋轉單一頁面或整份 PDF，儲存後方向就固定了。免費、免註冊、檔案不上傳。

🔒 檔案不會上傳，全程在您的瀏覽器中處理
選擇或拖放一個 PDF 檔案
檔案只在您的瀏覽器中處理

在每一頁按 ↺ 向左轉、↻ 向右轉；也可以刪除 🗑 或拖曳排序。

掃描時紙張放反、手機拍的文件變成橫的，或是一份 PDF 裡夾雜了幾張橫向表格？很多閱讀器的「旋轉」只會改變當下的檢視方向，關掉再打開又回到原樣。Waiting Studio 本機 PDF 的 PDF 旋轉會把方向直接寫進檔案，下載後用任何軟體開啟都會維持正確方向。您可以逐頁向左或向右轉 90 度，也可以一次旋轉全部頁面。

PDF 旋轉怎麼做？4 個步驟完成

  1. 選擇或拖曳 PDF 檔案進來，畫面會顯示每一頁的縮圖。
  2. 在需要調整的頁面按 ↺（向左轉）或 ↻（向右轉），縮圖會即時顯示旋轉後的方向；整份都反了，可按「全部向右轉」兩次轉成 180 度。
  3. 確認所有頁面方向都正確。
  4. 按「套用並下載 PDF」，儲存旋轉後的新檔案。

旋轉會影響畫質嗎？

不會。PDF 的每一頁都有一個「旋轉角度」設定，本工具只修改這個設定，不會重新繪製或壓縮內容，所以文字仍然可以選取、搜尋，畫質也和原檔一樣。若同時想調整頁面順序，可到 PDF 頁面排序，該頁面一樣提供旋轉功能。

在手機上怎麼操作？

  1. 用 Safari 開啟本頁，點選上方區域，從「檔案」App 選擇 PDF。
  2. 在方向不對的頁面點 ↺ 或 ↻。
  3. 按「套用並下載 PDF」。
  4. 在「檔案」App 開啟下載的檔案，確認方向已經固定。

檔案怎麼在本機處理？

PDF 的每一頁都有一個「旋轉角度」欄位。本工具用 Mozilla 的 PDF.js（Apache-2.0 授權） 畫出縮圖讓您確認方向，按下套用後用 pdf-lib（MIT 授權） 修改這個欄位並另存新檔，頁面內容本身不會被重畫。全程在瀏覽器中完成，不會上傳。

常見問題

旋轉後要怎麼儲存？

調整好方向後，按「套用並下載 PDF」，就會產生一個新的 PDF 並下載到您的裝置。方向已寫入檔案中，之後用 Adobe Reader、預覽程式或手機開啟都會維持正確方向，不需要每次重新旋轉。

可以只旋轉其中一頁嗎？

可以。每一頁縮圖下方都有獨立的 ↺ ↻ 按鈕，只會旋轉那一頁，其他頁面維持不變。

旋轉後文字還能搜尋嗎？

可以。只修改了頁面的旋轉角度，文字層完全保留。

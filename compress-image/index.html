    壓縮設定

    手機拍的照片動輒 3～5 MB，上傳到報名系統、網拍、部落格或用 Email 寄送時常常太大。Waiting Studio 本機 PDF 的圖片壓縮使用瀏覽器內建的影像編碼功能，在您的裝置上重新壓縮照片：可以調整品質、限制最長邊（例如 1920 px），並選擇輸出 JPG、WebP 或 PNG。可以一次處理多張，完成後每張都會顯示壓縮前後的大小，多張時自動打包成 ZIP 下載。

    圖片壓縮怎麼做？4 個步驟完成

    1. 選擇或拖曳圖片進來，可以一次選取多張。
    2. 選擇輸出格式、品質與最長邊尺寸；一般照片建議 JPG、品質 75、最長邊 1920 px。
    3. 按「壓縮圖片並下載」。
    4. 在清單中查看每張的前後大小，也可以個別重新下載。

    為什麼用 Waiting Studio 本機 PDF？

    • 無次數限制：不限每天使用次數、不限檔案數量，也不會要求您「升級」才能繼續。
    • 免註冊、免安裝：打開網頁就能用，不需要帳號、Email 或安裝 App。
    • 無彈出視窗：不跳出廣告視窗、不在下載前插播，也不加浮水印。
    • 檔案不上傳：全部在本機處理，適合合約、報價單、身分證件掃描檔等敏感資料。

    iPhone／Android 手機怎麼用？

    不必安裝任何 App，用手機瀏覽器開啟本頁即可。以 iPhone 為例：

    1. 用 Safari 開啟本頁，點選上方區域，選擇「照片圖庫」並勾選照片。
    2. 設定品質與尺寸後，按「壓縮圖片並下載」。
    3. 在下載提示中點選「下載」。
    4. 到「檔案」App 的「下載項目」開啟；單張圖片可再分享到「照片」。

    Android 手機的操作方式相同：在 Chrome 開啟本頁，選取檔案時可以從「檔案」或「雲端硬碟」挑選，完成後檔案會存到「下載」資料夾。

    品質與尺寸怎麼設定？

    對檔案大小影響最大的是「尺寸」：一張 4000×3000 的照片縮成最長邊 1920 px，像素只剩約四分之一，檔案通常也會小很多，而在手機與電腦螢幕上幾乎看不出差別。品質 70～80 是 JPG 常用的範圍；低於 50 會開始看到色塊。WebP 在相同畫質下通常比 JPG 更小，但少數舊系統或網站不支援。PNG 是無損格式，適合保留透明背景，但照片存成 PNG 通常反而變大。壓縮後若要合成 PDF，可以接著使用 JPG 轉 PDF。

    怎麼做到「不上傳」？運作原理說明

    一般的線上 PDF 工具，會先把您的檔案上傳到對方的伺服器，處理完再讓您下載，檔案在網路上走了一趟，也會在別人的主機上停留一段時間。Waiting Studio 本機 PDF 的做法不同：整個網站只是一組靜態網頁，打開頁面時，瀏覽器會下載處理 PDF 所需的程式碼，之後用瀏覽器內建的影像解碼讀取圖片，在畫布上縮放後重新編碼成 JPG、WebP 或 PNG都由您裝置上的瀏覽器直接計算完成。

    我們使用開源函式庫 pdf-lib（MIT 授權）讀取與產生 PDF 結構，並用 Mozilla 開發的 PDF.js（Apache-2.0 授權）繪製頁面縮圖。這些程式碼都放在本站，不從第三方 CDN 載入；網頁也設定了內容安全政策（CSP），限制可載入的程式來源；處理檔案的程式碼不會把檔案傳到任何地方。處理完成的檔案是在瀏覽器記憶體中產生，再透過「下載」存到您的裝置，從頭到尾沒有任何上傳的動作。您可以打開瀏覽器的開發者工具，在「網路」分頁自行確認。

    常見問題

    檔案會上傳到伺服器嗎？

    不會。圖片壓縮的過程全部在您的瀏覽器中完成，本站沒有接收檔案的伺服器，也不會保存任何副本。關閉分頁後，記憶體中的資料就會清除。

    安全嗎？會不會被別人看到？

    因為檔案不會離開您的裝置，第三方無從取得內容。本站不使用 Cookie、不做追蹤分析，也不載入外部腳本。使用公用電腦時，記得處理完把下載的檔案刪除即可。

    檔案大小或數量有限制嗎？

    本站沒有設定大小或數量上限，能壓縮幾張、實際能處理多大的檔案，取決於您裝置的記憶體。檔案較大時，手機可能會變慢或記憶體不足，建議分批處理。

    需要註冊或付費嗎？

    不需要。所有功能免費、免註冊、無次數限制。未來可能在頁面中加入一個固定的廣告版位以維持營運，但不會有彈出視窗，也會提供付費移除廣告的選項。

    手機可以用嗎？

    iPhone、iPad 與 Android 手機都可以使用，建議用 Safari 或 Chrome 開啟。介面會自動調整成適合手機的版面，按鈕也加大方便點選。

    壓縮後照片的拍攝資訊還在嗎？

    不在。重新編碼時不會保留 EXIF 資訊（例如拍攝時間、GPS 位置），這也能避免分享照片時不小心洩漏位置。

    支援 HEIC 嗎？

    本工具支援 JPG、PNG、WebP、GIF 與 BMP。iPhone 的 HEIC 照片可在「設定 > 相機 > 格式」改成「最相容」，或在分享時讓系統自動轉成 JPG。

    為什麼有些圖片壓縮後變大？

    原圖若已經高度壓縮，或把照片轉成 PNG，就可能變大。請降低品質、縮小尺寸，或改用 JPG／WebP 輸出。

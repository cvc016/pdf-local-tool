PDF 合併

把多個 PDF 檔案合併成一個，拖曳就能調整順序。免費、免註冊、檔案不上傳。

🔒 檔案不會上傳，全程在您的瀏覽器中處理
選擇或拖放 PDF 檔案
可一次選擇多個檔案

拖曳 ⠿ 或使用 ▲▼ 調整順序，由上到下合併。

    加入更多 PDF

    要把報告的封面、內文和附件合成一份？要把好幾張掃描的收據整理成一個檔案寄給會計？Waiting Studio 本機 PDF 的 PDF 合併工具可以一次選取多個 PDF，拖曳排好順序，按一下就合併成單一檔案。合併時直接複製原始頁面內容，文字、圖片與向量圖形都不會被重新壓縮，畫質和原檔完全相同。

    PDF 合併怎麼做？4 個步驟完成

    1. 點選上方的虛線區域，或直接把 PDF 檔案拖曳進來；可以一次選擇多個檔案。
    2. 在清單中拖曳 ⠿ 圖示，或使用 ▲▼ 按鈕調整檔案順序，系統會由上到下依序合併。
    3. 若還有檔案要加入，可按「加入更多 PDF」；不需要的檔案按 ✕ 移除。
    4. 按「合併 PDF 並下載」，合併好的檔案會直接儲存到您的裝置。

    合併前的小技巧

    如果只需要某個檔案中的幾頁，可以先用 PDF 分割 擷取需要的頁面，再回來合併；合併後若發現有多餘的頁面，可用 刪除 PDF 頁面 移除，或用 PDF 頁面排序 微調順序。加密或設有開啟密碼的 PDF 目前無法合併，請先用原本的軟體移除密碼。

    在手機上怎麼操作？

    1. 用 Safari 開啟本頁，點選上方區域。
    2. 選擇「瀏覽」從「檔案」App 挑選 PDF；若 PDF 在 LINE 或郵件中，請先「儲存到檔案」。
    3. 用 ▲▼ 按鈕調整順序（也可以按住 ⠿ 拖曳）。
    4. 按「合併 PDF 並下載」，再到「檔案」App 的「下載項目」找到合併後的檔案。

    想把手機照片合併成 PDF，請改用 圖片轉 PDF。

    遇到問題怎麼辦？

    出現「有密碼保護或已加密，目前不支援」
    設有開啟密碼或權限保護的 PDF 無法合併。請用您有權限的軟體（例如 Adobe Acrobat 或原本產生檔案的系統）先移除保護，再回來合併。
    「合併 PDF 並下載」按鈕按不下去
    清單裡至少要有 2 個檔案才能合併。若只選了一個檔案，請按「加入更多 PDF」再選一個。
    合併後檔案比預期大
    合併不會壓縮內容，所以大小約等於所有檔案相加。若需要上傳到有大小限制的系統，可以接著用 壓縮 PDF。
    手機上選不到 LINE 收到的 PDF
    請先在 LINE 開啟檔案，選「分享」→「儲存到檔案」，再從「檔案」App 選取。

    檔案怎麼在本機處理？

    選好檔案後，瀏覽器用 pdf-lib（MIT 授權） 讀取每個 PDF，把頁面物件依清單順序複製到一個新文件，再把新文件交給瀏覽器下載。頁面內容（文字、字型、向量圖、圖片）是原封不動複製，不會重新繪製或壓縮。整個過程沒有任何網路傳輸，本站的程式也不會把檔案交給廣告程式或任何第三方。

    常見問題

    合併後畫質會變差嗎？

    不會。合併只是把原本的頁面物件複製到新檔案，不會重新壓縮圖片或轉換文字，畫質與原始檔案相同。

    合併後書籤和超連結還在嗎？

    頁面上的超連結通常會保留，但原檔的書籤（目錄）不會帶到合併後的檔案。需要書籤的正式文件，建議用桌面版 PDF 軟體合併。

    可以合併幾個檔案？

    程式沒有設定數量上限，限制來自裝置記憶體。我們在電腦上合併數十個一般文件沒有問題；手機若檔案很大，建議分批合併。

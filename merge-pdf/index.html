    加入更多 PDF

    要把報告的封面、內文和附件合成一份？要把好幾張掃描的收據整理成一個檔案寄給會計？本機PDF 的 PDF 合併工具可以一次選取多個 PDF，拖曳排好順序，按一下就合併成單一檔案。合併時直接複製原始頁面內容，文字、圖片與向量圖形都不會被重新壓縮，畫質和原檔完全相同。

    PDF 合併怎麼做？4 個步驟完成

    1. 點選上方的虛線區域，或直接把 PDF 檔案拖曳進來；可以一次選擇多個檔案。
    2. 在清單中拖曳 ⠿ 圖示，或使用 ▲▼ 按鈕調整檔案順序，系統會由上到下依序合併。
    3. 若還有檔案要加入，可按「加入更多 PDF」；不需要的檔案按 ✕ 移除。
    4. 按「合併 PDF 並下載」，合併好的檔案會直接儲存到您的裝置。

    為什麼用 本機PDF？

    • 無次數限制：不限每天使用次數、不限檔案數量，也不會要求您「升級」才能繼續。
    • 免註冊、免安裝：打開網頁就能用，不需要帳號、Email 或安裝 App。
    • 無彈出視窗：不跳出廣告視窗、不在下載前插播，也不加浮水印。
    • 檔案不上傳：全部在本機處理，適合合約、報價單、身分證件掃描檔等敏感資料。
    廣告

    iPhone／Android 手機怎麼用？

    不必安裝任何 App，用手機瀏覽器開啟本頁即可。以 iPhone 為例：

    1. 用 Safari 開啟本頁，點選上方區域。
    2. 選擇「瀏覽」從「檔案」App 挑選 PDF；若 PDF 在 LINE 或郵件中，請先「儲存到檔案」。
    3. 用 ▲▼ 按鈕調整順序（也可以按住 ⠿ 拖曳）。
    4. 按「合併 PDF 並下載」，再到「檔案」App 的「下載項目」找到合併後的檔案。

    Android 手機的操作方式相同：在 Chrome 開啟本頁，選取檔案時可以從「檔案」或「雲端硬碟」挑選，完成後檔案會存到「下載」資料夾。想把手機照片合併成 PDF，請改用 圖片轉 PDF。

    合併前的小技巧

    如果只需要某個檔案中的幾頁，可以先用 PDF 分割 擷取需要的頁面，再回來合併；合併後若發現有多餘的頁面，可用 刪除 PDF 頁面 移除，或用 PDF 頁面排序 微調順序。加密或設有開啟密碼的 PDF 目前無法合併，請先用原本的軟體移除密碼。

    怎麼做到「不上傳」？運作原理說明

    一般的線上 PDF 工具，會先把您的檔案上傳到對方的伺服器，處理完再讓您下載，檔案在網路上走了一趟，也會在別人的主機上停留一段時間。本機PDF 的做法不同：整個網站只是一組靜態網頁，打開頁面時，瀏覽器會下載處理 PDF 所需的程式碼，之後讀取每個 PDF、複製頁面、組合成新檔案都由您裝置上的瀏覽器直接計算完成。

    我們使用開源函式庫 pdf-lib（MIT 授權）讀取與產生 PDF 結構，並用 Mozilla 開發的 PDF.js（Apache-2.0 授權）繪製頁面縮圖。這些程式碼都放在本站，不從第三方 CDN 載入；網頁也設定了內容安全政策（CSP），限制只能連線到本站。處理完成的檔案是在瀏覽器記憶體中產生，再透過「下載」存到您的裝置，從頭到尾沒有任何上傳的動作。您可以打開瀏覽器的開發者工具，在「網路」分頁自行確認。

    常見問題

    檔案會上傳到伺服器嗎？

    不會。合併的過程全部在您的瀏覽器中完成，本站沒有接收檔案的伺服器，也不會保存任何副本。關閉分頁後，記憶體中的資料就會清除。

    安全嗎？會不會被別人看到？

    因為檔案不會離開您的裝置，第三方無從取得內容。本站不使用 Cookie、不做追蹤分析，也不載入外部腳本。使用公用電腦時，記得處理完把下載的檔案刪除即可。

    檔案大小或數量有限制嗎？

    本站沒有設定大小或數量上限，能合併幾個、實際能處理多大的檔案，取決於您裝置的記憶體。檔案較大時，手機可能會變慢或記憶體不足，建議分批處理。

    需要註冊或付費嗎？

    不需要。所有功能免費、免註冊、無次數限制。未來可能在頁面中加入一個固定的廣告版位以維持營運，但不會有彈出視窗，也會提供付費移除廣告的選項。

    手機可以用嗎？

    iPhone、iPad 與 Android 手機都可以使用，建議用 Safari 或 Chrome 開啟。介面會自動調整成適合手機的版面，按鈕也加大方便點選。

    旋轉後要怎麼儲存？

    在 PDF 旋轉 頁面調整好方向後，按「套用並下載 PDF」，就會產生一個新的 PDF 檔案並下載到您的裝置。之後用任何閱讀器打開，頁面都會維持您設定的方向，不需要每次重新旋轉。

    合併後畫質會變差嗎？

    不會。合併只是把原本的頁面物件複製到新檔案，不會重新壓縮圖片或轉換文字，畫質與原始檔案相同。

隱私權政策

最後更新：2026-10-28

1. 您的檔案不會上傳

本機PDF（以下稱「本站」）的所有 PDF 與圖片處理，都在您的瀏覽器中以 JavaScript 執行。您選擇的檔案只會被讀入您裝置的記憶體，處理結果直接下載到您的裝置。本站沒有接收、儲存或檢視您檔案的伺服器，我們無法取得您的檔案內容。

2. 本站目前收集的資料

本站是放在 GitHub Pages 的靜態網站，目前不使用 Cookie、不使用任何分析或追蹤工具，也不載入第三方腳本。與一般網站相同，主機服務商 GitHub 可能為了安全與維運記錄連線資訊（例如 IP 位址、瀏覽器類型），相關處理請參考 GitHub 隱私聲明。

3. 本機儲存（localStorage）

若您購買並啟用「移除廣告」，授權碼與啟用狀態會儲存在您瀏覽器的 localStorage 中，只存在您的裝置上。您可以在 移除廣告 頁面清除，或清除瀏覽器的網站資料。

4. 廣告與第三方 Cookie（未來可能啟用）

本站目前沒有任何廣告。未來為了維持免費營運，可能在頁面中加入一個固定的廣告版位，不會使用彈出式視窗。啟用前我們會更新本政策，屆時適用以下說明：

  • 第三方廠商（包括 Google）會使用 Cookie，根據使用者先前造訪本站或其他網站的紀錄放送廣告。
  • Google 使用廣告 Cookie，讓 Google 及其合作夥伴能根據使用者造訪本站和網路上其他網站的情形，放送合適的廣告。
  • 您可以前往 Google 廣告設定 停用個人化廣告，或前往 www.aboutads.info 停用第三方廠商用於個人化廣告的 Cookie。
  • （預留）本站的 Cookie 同意與個人化廣告退出設定將放在這裡。

無論是否啟用廣告，您的 PDF 與圖片檔案都不會傳送給廣告商或任何第三方。

5. 付款

「移除廣告」的付款將由第三方平台（預計為 Gumroad）處理，本站不會接觸您的信用卡資料。驗證授權碼時，只會把授權碼送到該平台確認是否有效。

6. 兒童隱私

本站不會刻意收集任何人的個人資料，包括兒童。

7. 政策變更與聯絡方式

本政策如有修改，會在本頁更新並註明日期。若有任何問題，請參考 關於與聯絡。

    樣式與輸出

    浮水印直接畫進圖片像素，無法被一鍵移除；請保留原檔。

    辦手機門號、租屋、申請貸款或報名活動時，常常要傳身分證、健保卡或存摺封面的照片。為了避免影本被拿去做其他用途，建議在上面加上「僅供 ○○ 申請使用」與日期的浮水印。Waiting Studio 本機 PDF 的圖片加浮水印直接在您的瀏覽器中把文字畫進圖片，支援中文與多行文字，可以斜向平鋪整張（證件最推薦）、中央斜放或放在右下、左下角，並調整字的大小、不透明度與顏色。證件照片完全不會上傳，處理後的浮水印也無法被一鍵移除。

    圖片加浮水印怎麼做？4 個步驟完成

    1. 選擇或拖曳要加浮水印的圖片，可以一次選取多張。
    2. 輸入浮水印文字，例如「僅供 ○○ 銀行開戶使用 2026/11/03」，可按 Enter 換行。
    3. 選擇位置（斜向平鋪、中央、角落），調整大小、不透明度與顏色；清單縮圖會即時更新。
    4. 按「加上浮水印並下載」：單張直接下載，多張打包成「浮水印圖片.zip」。

    為什麼用 Waiting Studio 本機 PDF？

    • 無次數限制：不限每天使用次數、不限檔案數量，也不會要求您「升級」才能繼續。
    • 免註冊、免安裝：打開網頁就能用，不需要帳號、Email 或安裝 App。
    • 無彈出視窗：不跳出廣告視窗、不在下載前插播，也不加浮水印。
    • 檔案不上傳：全部在本機處理，適合合約、報價單、身分證件掃描檔等敏感資料。

    iPhone／Android 手機怎麼用？

    不必安裝任何 App，用手機瀏覽器開啟本頁即可。以 iPhone 為例：

    1. 用 Safari 開啟本頁，點選上方區域，選擇「照片圖庫」或「拍照」。
    2. 輸入浮水印文字並選擇位置與透明度。
    3. 按「加上浮水印並下載」，在下載提示中點選「下載」。
    4. 到「檔案」App 的「下載項目」開啟，分享到「照片」或直接傳送。

    Android 手機的操作方式相同：在 Chrome 開啟本頁，選取檔案時可以從「檔案」或「雲端硬碟」挑選，完成後檔案會存到「下載」資料夾。

    證件影本浮水印怎麼寫？

    建議寫清楚用途、對象與日期，例如「僅供 ○○ 電信門號申辦使用 2026/11/03」「僅供租屋簽約使用，他用無效」。選「斜向平鋪」讓文字覆蓋整張證件，並讓字壓過姓名、證號與照片等重要欄位，不透明度 30～45% 既能看清證件內容，又不容易被修圖去除。顏色可選灰色或紅色。處理後請先放大檢查證件資料仍清晰可讀，再傳給對方；原始未加浮水印的照片請自行妥善保存。要把多張證件合成一份文件，可以接著用 JPG 轉 PDF；檔案太大可用 圖片壓縮。

    怎麼做到「不上傳」？運作原理說明

    一般的線上 PDF 工具，會先把您的檔案上傳到對方的伺服器，處理完再讓您下載，檔案在網路上走了一趟，也會在別人的主機上停留一段時間。Waiting Studio 本機 PDF 的做法不同：整個網站只是一組靜態網頁，打開頁面時，瀏覽器會下載處理 PDF 所需的程式碼，之後用瀏覽器內建的影像解碼讀取圖片，在畫布上繪製浮水印文字後重新編碼都由您裝置上的瀏覽器直接計算完成。

    我們使用開源函式庫 pdf-lib（MIT 授權）讀取與產生 PDF 結構，並用 Mozilla 開發的 PDF.js（Apache-2.0 授權）繪製頁面縮圖。這些程式碼都放在本站，不從第三方 CDN 載入；網頁也設定了內容安全政策（CSP），限制可載入的程式來源；處理檔案的程式碼不會把檔案傳到任何地方。處理完成的檔案是在瀏覽器記憶體中產生，再透過「下載」存到您的裝置，從頭到尾沒有任何上傳的動作。您可以打開瀏覽器的開發者工具，在「網路」分頁自行確認。

    常見問題

    檔案會上傳到伺服器嗎？

    不會。加浮水印的過程全部在您的瀏覽器中完成，本站沒有接收檔案的伺服器，也不會保存任何副本。關閉分頁後，記憶體中的資料就會清除。

    安全嗎？會不會被別人看到？

    因為檔案不會離開您的裝置，第三方無從取得內容。本站不使用 Cookie、不做追蹤分析，也不載入外部腳本。使用公用電腦時，記得處理完把下載的檔案刪除即可。

    檔案大小或數量有限制嗎？

    本站沒有設定大小或數量上限，能處理幾張、實際能處理多大的檔案，取決於您裝置的記憶體。檔案較大時，手機可能會變慢或記憶體不足，建議分批處理。

    需要註冊或付費嗎？

    不需要。所有功能免費、免註冊、無次數限制。未來可能在頁面中加入一個固定的廣告版位以維持營運，但不會有彈出視窗，也會提供付費移除廣告的選項。

    手機可以用嗎？

    iPhone、iPad 與 Android 手機都可以使用，建議用 Safari 或 Chrome 開啟。介面會自動調整成適合手機的版面，按鈕也加大方便點選。

    浮水印可以被移除嗎？

    浮水印是直接畫進圖片像素，不是另外一層，無法一鍵移除。平鋪並壓過重要欄位，會讓修圖去除變得很困難。

    可以用圖片或 Logo 當浮水印嗎？

    目前只支援文字浮水印（含中文、多行）。

    可以用在 PDF 嗎？

    本工具處理圖片。PDF 可以先用 PDF 轉 JPG 轉成圖片，加上浮水印後再用 JPG 轉 PDF 合成。

掃描文件時多掃了幾張空白頁、簡報匯出的 PDF 有不想給客戶看的備註頁，或只是想刪掉其中一頁？Waiting Studio 本機 PDF 會把每一頁顯示成縮圖，點一下垃圾桶就能標記刪除，按錯了再按一次就能還原。另外提供「自動標記空白頁」功能，會逐頁檢查內容，把幾乎沒有內容的頁面一次標記起來，處理雙面掃描檔特別方便。

PDF 刪除頁面怎麼做？4 個步驟完成

  1. 選擇或拖曳要處理的 PDF 檔案，畫面會顯示所有頁面的縮圖。
  2. 在要刪除的頁面按 🗑，頁面會變淡並標示刪除線；按 ↩ 可以還原。
  3. 若有很多空白頁，可按「自動標記空白頁」，系統會自動標記，請再檢查一次結果。
  4. 按「套用並下載 PDF」，就會得到刪除頁面後的新檔案。

空白頁偵測怎麼判斷？

系統會把每一頁縮小繪製，計算非白色像素的比例，若幾乎全白就視為空白頁。掃描時帶到的淡淡紙紋通常也會被判定為空白，但有頁碼或頁首文字的頁面不會被標記。自動偵測只是幫您先勾選，下載前仍建議看過一次縮圖。若需要的是取出少數幾頁，可以改用 PDF 分割 的擷取功能。

在手機上怎麼操作？

  1. 用 Safari 開啟本頁，點選上方區域，從「檔案」App 選擇 PDF。
  2. 縮圖會以多欄顯示，在不要的頁面點 🗑。
  3. 確認右上方顯示的「保留 X / Y 頁」是否正確。
  4. 按「套用並下載 PDF」，到「檔案」App 的「下載項目」開啟新檔案。

遇到問題怎麼辦？

自動標記把有內容的頁面也標起來了
幾乎全白、只有極少量淡色內容的頁面（例如只有很淡的鉛筆字）可能被判定為空白。自動標記只是預先勾選，請在下載前看過縮圖，按 ↩ 還原誤標的頁面。
掃描檔的空白頁沒有被標記
紙張背面透出的字、裝訂孔陰影或掃描邊框，會讓頁面不被當成空白。這些頁面請手動按 🗑。
縮圖一直顯示不出來
縮圖會在捲動到畫面時才繪製。頁數很多或頁面很複雜時，請稍候或往下捲動。

檔案怎麼在本機處理？

縮圖由 Mozilla 的 PDF.js（Apache-2.0 授權） 在瀏覽器裡繪製；「自動標記空白頁」也是在您的裝置上把每一頁縮小繪製、計算白色像素比例來判斷。按下套用後，pdf-lib（MIT 授權） 只把保留的頁面複製到新檔案。原檔不會被修改，處理過程沒有任何上傳。

常見問題

刪除頁面後還能救回來嗎？

本工具不會修改原始檔案，而是另外產生一個新的 PDF，原檔仍保留在您的裝置上，隨時可以重新處理。

可以一次刪除很多頁嗎？

可以，逐頁點 🗑 即可，上方會顯示「保留 X / Y 頁」。如果要保留的頁面比較少，改用 PDF 分割 直接擷取會更快。

刪除頁面會影響其他頁的畫質嗎？

不會。保留的頁面是原封不動複製，文字仍可選取、搜尋。

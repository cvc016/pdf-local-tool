在要刪除的頁面按 🗑（再按 ↩ 可還原）；也可以順便旋轉 ↺↻ 或拖曳排序。

掃描文件時多掃了幾張空白頁、簡報匯出的 PDF 有不想給客戶看的備註頁，或只是想刪掉其中一頁？本機PDF 會把每一頁顯示成縮圖，點一下垃圾桶就能標記刪除，按錯了再按一次就能還原。另外提供「自動標記空白頁」功能，會逐頁檢查內容，把幾乎沒有內容的頁面一次標記起來，處理雙面掃描檔特別方便。

PDF 刪除頁面怎麼做？4 個步驟完成

  1. 選擇或拖曳要處理的 PDF 檔案，畫面會顯示所有頁面的縮圖。
  2. 在要刪除的頁面按 🗑，頁面會變淡並標示刪除線；按 ↩ 可以還原。
  3. 若有很多空白頁，可按「自動標記空白頁」，系統會自動標記，請再檢查一次結果。
  4. 按「套用並下載 PDF」，就會得到刪除頁面後的新檔案。

為什麼用 本機PDF？

  • 無次數限制：不限每天使用次數、不限檔案數量，也不會要求您「升級」才能繼續。
  • 免註冊、免安裝：打開網頁就能用，不需要帳號、Email 或安裝 App。
  • 無彈出視窗：不跳出廣告視窗、不在下載前插播，也不加浮水印。
  • 檔案不上傳：全部在本機處理，適合合約、報價單、身分證件掃描檔等敏感資料。
廣告

iPhone／Android 手機怎麼用？

不必安裝任何 App，用手機瀏覽器開啟本頁即可。以 iPhone 為例：

  1. 用 Safari 開啟本頁，點選上方區域，從「檔案」App 選擇 PDF。
  2. 縮圖會以多欄顯示，在不要的頁面點 🗑。
  3. 確認右上方顯示的「保留 X / Y 頁」是否正確。
  4. 按「套用並下載 PDF」，到「檔案」App 的「下載項目」開啟新檔案。

Android 手機的操作方式相同：在 Chrome 開啟本頁，選取檔案時可以從「檔案」或「雲端硬碟」挑選，完成後檔案會存到「下載」資料夾。

空白頁偵測怎麼判斷？

系統會把每一頁縮小繪製，計算非白色像素的比例，若幾乎全白就視為空白頁。掃描時帶到的淡淡紙紋通常也會被判定為空白，但有頁碼或頁首文字的頁面不會被標記。自動偵測只是幫您先勾選，下載前仍建議看過一次縮圖。若需要的是取出少數幾頁，可以改用 PDF 分割 的擷取功能。

怎麼做到「不上傳」？運作原理說明

一般的線上 PDF 工具，會先把您的檔案上傳到對方的伺服器，處理完再讓您下載，檔案在網路上走了一趟，也會在別人的主機上停留一段時間。本機PDF 的做法不同：整個網站只是一組靜態網頁，打開頁面時，瀏覽器會下載處理 PDF 所需的程式碼，之後讀取 PDF、偵測空白頁、移除您標記的頁面並產生新檔案都由您裝置上的瀏覽器直接計算完成。

我們使用開源函式庫 pdf-lib（MIT 授權）讀取與產生 PDF 結構，並用 Mozilla 開發的 PDF.js（Apache-2.0 授權）繪製頁面縮圖。這些程式碼都放在本站，不從第三方 CDN 載入；網頁也設定了內容安全政策（CSP），限制只能連線到本站。處理完成的檔案是在瀏覽器記憶體中產生，再透過「下載」存到您的裝置，從頭到尾沒有任何上傳的動作。您可以打開瀏覽器的開發者工具，在「網路」分頁自行確認。

常見問題

檔案會上傳到伺服器嗎？

不會。刪除頁面的過程全部在您的瀏覽器中完成，本站沒有接收檔案的伺服器，也不會保存任何副本。關閉分頁後，記憶體中的資料就會清除。

安全嗎？會不會被別人看到？

因為檔案不會離開您的裝置，第三方無從取得內容。本站不使用 Cookie、不做追蹤分析，也不載入外部腳本。使用公用電腦時，記得處理完把下載的檔案刪除即可。

檔案大小或數量有限制嗎？

本站沒有設定大小或數量上限，實際能處理多大的檔案，取決於您裝置的記憶體。一般電腦處理數百 MB 都沒問題；手機建議單次處理 100 MB 以內，若出現卡頓，可分批進行。

需要註冊或付費嗎？

不需要。所有功能免費、免註冊、無次數限制。未來可能在頁面中加入一個固定的廣告版位以維持營運，但不會有彈出視窗，也會提供付費移除廣告的選項。

手機可以用嗎？

iPhone、iPad 與 Android 手機都可以使用，建議用 Safari 或 Chrome 開啟。介面會自動調整成適合手機的版面，按鈕也加大方便點選。

旋轉後要怎麼儲存？

在 PDF 旋轉 頁面調整好方向後，按「套用並下載 PDF」，就會產生一個新的 PDF 檔案並下載到您的裝置。之後用任何閱讀器打開，頁面都會維持您設定的方向，不需要每次重新旋轉。

刪除頁面後還能救回來嗎？

本工具不會修改原始檔案，而是另外產生一個新的 PDF，原檔仍保留在您的裝置上，隨時可以重新處理。

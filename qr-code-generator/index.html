QR Code 內容



  

    
很多「免費 QR Code」網站產生的其實是動態碼：QR Code 裡存的是對方的短網址，掃描時先經過他們的伺服器再轉到您的網址。試用期一過或對方停止服務，印在傳單、菜單、名片上的 QR Code 就失效了。Waiting Studio 本機 PDF 產生的是靜態 QR Code，您的網址或文字直接編碼在圖案裡，掃描時不經過任何第三方，只要內容本身有效，就永久可以使用，也不需要註冊或登入。

    
QR Code 產生器怎麼做？4 個步驟完成

    
  1. 選擇內容類型：網址、文字、Wi-Fi、名片、LINE 或轉帳資訊。
  2. 填入內容，右側會即時顯示 QR Code。
  3. 需要的話調整顏色、容錯等級，或上傳 Logo 放在中間。
  4. 按「下載 PNG」或「下載 SVG（向量）」，並先用手機實際掃描確認。

iPhone／Android 手機怎麼用？


不必安裝任何 App，用手機瀏覽器開啟本頁即可。以 iPhone 為例：


  1. 用 Safari 開啟本頁，選擇內容類型並輸入內容。
  2. 確認預覽的 QR Code，可用另一支手機掃描測試。
  3. 按「下載 PNG」，在下載提示中點選「下載」。
  4. 到「檔案」App 的「下載項目」開啟圖片，分享到「照片」或 LINE。


Android 手機的操作方式相同：在 Chrome 開啟本頁，選取檔案時可以從「檔案」或「雲端硬碟」挑選，完成後檔案會存到「下載」資料夾。要印刷時建議在電腦上下載 SVG 或 2048 px 的 PNG。

    
PNG 和 SVG 該下載哪一個？


PNG 是一般圖片，貼到 LINE、簡報、社群貼文最方便；1024 px 足夠螢幕與一般 A4 列印使用，海報或大型印刷可選 2048 px。SVG 是向量格式，放大到任何尺寸都不會模糊，適合交給設計師、印刷廠或放進 Illustrator、Canva 排版。顏色方面，請維持「深色前景、淺色背景」並保留足夠對比，反白或淺色前景很多手機掃不到。放 Logo 時本工具會自動改用最高容錯（H），Logo 只佔中央一小塊，仍建議印刷前實際掃描測試。要把 QR Code 放進文件，可以搭配 JPG 轉 PDF；圖片太大則可用 圖片壓縮。

    
怎麼做到「不上傳」？運作原理說明


一般的線上 PDF 工具，會先把您的檔案上傳到對方的伺服器，處理完再讓您下載，檔案在網路上走了一趟，也會在別人的主機上停留一段時間。Waiting Studio 本機 PDF 的做法不同：整個網站只是一組靜態網頁，打開頁面時，瀏覽器會下載處理 PDF 所需的程式碼，之後用開源函式庫 qrcode-generator（MIT 授權）計算 QR Code 圖案，並由瀏覽器繪製成 SVG 或 PNG都由您裝置上的瀏覽器直接計算完成。


我們使用開源函式庫 pdf-lib（MIT 授權）讀取與產生 PDF 結構，並用 Mozilla 開發的 PDF.js（Apache-2.0 授權）繪製頁面縮圖。這些程式碼都放在本站，不從第三方 CDN 載入；網頁也設定了內容安全政策（CSP），限制可載入的程式來源；處理檔案的程式碼不會把檔案傳到任何地方。處理完成的檔案是在瀏覽器記憶體中產生，再透過「下載」存到您的裝置，從頭到尾沒有任何上傳的動作。您可以打開瀏覽器的開發者工具，在「網路」分頁自行確認。

    
常見問題


輸入的內容會上傳嗎？
不會。QR Code 是由您瀏覽器中的程式計算產生，網址、Wi-Fi 密碼、名片資料都不會傳到任何伺服器。


這個 QR Code 會過期嗎？
不會。這是靜態 QR Code，內容直接編碼在圖案裡，沒有經過本站或任何短網址轉址，因此不會因為試用到期或服務停止而失效。只有當您編碼的網址本身失效時才掃不到。


產生後可以修改內容嗎？
靜態 QR Code 無法事後修改內容；要改內容請重新產生一個。若確定網址會變動，可以先指向您自己能管理的網頁，再在該網頁更新內容。


需要註冊或付費嗎？
不需要。所有功能免費、免註冊、無次數限制。未來可能在頁面中加入一個固定的廣告版位以維持營運，但不會有彈出視窗，也會提供付費移除廣告的選項。


手機可以用嗎？
iPhone、iPad 與 Android 手機都可以使用，建議用 Safari 或 Chrome 開啟。介面會自動調整成適合手機的版面，按鈕也加大方便點選。


轉帳資訊 QR Code 可以直接付款嗎？
不行。它是純文字 QR Code，掃描後會顯示銀行代碼、帳號與金額，讓對方複製到網銀或行動銀行 App 轉帳；它不是銀行或 TWQR 的付款碼。


可以商業使用嗎？
可以。產生的 QR Code 圖片可自由用於商業用途，本站不加浮水印。「QR Code」是 DENSO WAVE 的註冊商標。

拖曳縮圖調整順序（手機請按住 ⠿ 拖曳）；也可以旋轉 ↺↻ 或刪除 🗑。

掃描的頁面順序亂了、雙面掃描變成倒序，或是想把附件移到最前面？本機PDF 會把 PDF 每一頁顯示成縮圖，用滑鼠拖曳（手機按住 ⠿ 拖曳）就能調整位置，看得到內容，排起來不容易出錯。若整份文件的順序剛好顛倒，按「反轉順序」一次就能全部倒過來。排序時也可以順便旋轉或刪除頁面。

PDF 頁面順序調整怎麼做？4 個步驟完成

  1. 選擇或拖曳 PDF 檔案進來，畫面會顯示所有頁面的縮圖。
  2. 用滑鼠拖曳縮圖到新的位置；手機請按住縮圖右下角的 ⠿ 再拖曳。
  3. 整份順序顛倒時按「反轉順序」；排錯了可按「復原全部」重新開始。
  4. 按「套用並下載 PDF」，下載排好順序的新檔案。

為什麼用 本機PDF？

  • 無次數限制：不限每天使用次數、不限檔案數量，也不會要求您「升級」才能繼續。
  • 免註冊、免安裝：打開網頁就能用，不需要帳號、Email 或安裝 App。
  • 無彈出視窗：不跳出廣告視窗、不在下載前插播，也不加浮水印。
  • 檔案不上傳：全部在本機處理，適合合約、報價單、身分證件掃描檔等敏感資料。
廣告

iPhone／Android 手機怎麼用？

不必安裝任何 App，用手機瀏覽器開啟本頁即可。以 iPhone 為例：

  1. 用 Safari 開啟本頁，點選上方區域，從「檔案」App 選擇 PDF。
  2. 按住頁面右下角的 ⠿ 圖示，拖曳到想要的位置後放開；拖到畫面邊緣會自動捲動。
  3. 確認順序後，按「套用並下載 PDF」。
  4. 到「檔案」App 的「下載項目」查看新檔案。

Android 手機的操作方式相同：在 Chrome 開啟本頁，選取檔案時可以從「檔案」或「雲端硬碟」挑選，完成後檔案會存到「下載」資料夾。

常見的排序情境

  • 雙面掃描順序錯亂：先掃完正面、再掃背面時，背面通常是倒序，可先用「反轉順序」，再微調位置。
  • 把多個檔案合併後再排序：先用 PDF 合併 合成一個檔案，再到本頁調整頁面順序。
  • 只想移除幾頁：可以在本頁按 🗑，或使用專門的 刪除 PDF 頁面。

怎麼做到「不上傳」？運作原理說明

一般的線上 PDF 工具，會先把您的檔案上傳到對方的伺服器，處理完再讓您下載，檔案在網路上走了一趟，也會在別人的主機上停留一段時間。本機PDF 的做法不同：整個網站只是一組靜態網頁，打開頁面時，瀏覽器會下載處理 PDF 所需的程式碼，之後讀取 PDF、依照新的順序重新組合頁面並產生新檔案都由您裝置上的瀏覽器直接計算完成。

我們使用開源函式庫 pdf-lib（MIT 授權）讀取與產生 PDF 結構，並用 Mozilla 開發的 PDF.js（Apache-2.0 授權）繪製頁面縮圖。這些程式碼都放在本站，不從第三方 CDN 載入；網頁也設定了內容安全政策（CSP），限制只能連線到本站。處理完成的檔案是在瀏覽器記憶體中產生，再透過「下載」存到您的裝置，從頭到尾沒有任何上傳的動作。您可以打開瀏覽器的開發者工具，在「網路」分頁自行確認。

常見問題

檔案會上傳到伺服器嗎？

不會。調整順序的過程全部在您的瀏覽器中完成，本站沒有接收檔案的伺服器，也不會保存任何副本。關閉分頁後，記憶體中的資料就會清除。

安全嗎？會不會被別人看到？

因為檔案不會離開您的裝置，第三方無從取得內容。本站不使用 Cookie、不做追蹤分析，也不載入外部腳本。使用公用電腦時，記得處理完把下載的檔案刪除即可。

檔案大小或數量有限制嗎？

本站沒有設定大小或數量上限，實際能處理多大的檔案，取決於您裝置的記憶體。檔案較大時，手機可能會變慢或記憶體不足，建議分批處理。

需要註冊或付費嗎？

不需要。所有功能免費、免註冊、無次數限制。未來可能在頁面中加入一個固定的廣告版位以維持營運，但不會有彈出視窗，也會提供付費移除廣告的選項。

手機可以用嗎？

iPhone、iPad 與 Android 手機都可以使用，建議用 Safari 或 Chrome 開啟。介面會自動調整成適合手機的版面，按鈕也加大方便點選。

旋轉後要怎麼儲存？

在 PDF 旋轉 頁面調整好方向後，按「套用並下載 PDF」，就會產生一個新的 PDF 檔案並下載到您的裝置。之後用任何閱讀器打開，頁面都會維持您設定的方向，不需要每次重新旋轉。

頁數很多時會不會很慢？

縮圖會在捲動到畫面時才繪製，即使數百頁也能流暢操作。實際產生新檔案通常只需要幾秒鐘。

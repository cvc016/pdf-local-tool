拖曳縮圖調整順序（手機請按住 ⠿ 拖曳）；也可以旋轉 ↺↻ 或刪除 🗑。

掃描的頁面順序亂了、雙面掃描變成倒序，或是想把附件移到最前面？Waiting Studio 本機 PDF 會把 PDF 每一頁顯示成縮圖，用滑鼠拖曳（手機按住 ⠿ 拖曳）就能調整位置，看得到內容，排起來不容易出錯。若整份文件的順序剛好顛倒，按「反轉順序」一次就能全部倒過來。排序時也可以順便旋轉或刪除頁面。

PDF 頁面順序調整怎麼做？4 個步驟完成

  1. 選擇或拖曳 PDF 檔案進來，畫面會顯示所有頁面的縮圖。
  2. 用滑鼠拖曳縮圖到新的位置；手機請按住縮圖右下角的 ⠿ 再拖曳。
  3. 整份順序顛倒時按「反轉順序」；排錯了可按「復原全部」重新開始。
  4. 按「套用並下載 PDF」，下載排好順序的新檔案。

常見的排序情境

  • 雙面掃描順序錯亂：先掃完正面、再掃背面時，背面通常是倒序，可先用「反轉順序」，再微調位置。
  • 把多個檔案合併後再排序：先用 PDF 合併 合成一個檔案，再到本頁調整頁面順序。
  • 只想移除幾頁：可以在本頁按 🗑，或使用專門的 刪除 PDF 頁面。

在手機上怎麼操作？

  1. 用 Safari 開啟本頁，點選上方區域，從「檔案」App 選擇 PDF。
  2. 按住頁面右下角的 ⠿ 圖示，拖曳到想要的位置後放開；拖到畫面邊緣會自動捲動。
  3. 確認順序後，按「套用並下載 PDF」。
  4. 到「檔案」App 的「下載項目」查看新檔案。

遇到問題怎麼辦？

手機上拖曳時畫面一直捲動
請按住縮圖右下角的 ⠿ 再拖曳；直接拖曳縮圖本身會被當成捲動頁面。拖到畫面邊緣時會自動捲動。
排錯了想重來
按「復原全部」會回到原本的順序與方向。
雙面掃描的背面全部倒序
先按「反轉順序」，再把正面與背面交錯排好；若頁數多，可以先用 PDF 分割 把正面和背面拆成兩份。

檔案怎麼在本機處理？

頁面縮圖由 Mozilla 的 PDF.js（Apache-2.0 授權） 在您的瀏覽器裡繪製，拖曳排序只是在畫面上調整順序；按下套用時，pdf-lib（MIT 授權） 依新順序把頁面複製到新檔案，同時套用您做的旋轉與刪除。不會修改原檔，也沒有網路傳輸。

常見問題

頁數很多時會不會很慢？

縮圖會在捲動到畫面時才繪製，即使數百頁也能流暢操作。實際產生新檔案通常只需要幾秒鐘。

排序時可以順便刪頁嗎？

可以，每張縮圖都有 🗑 按鈕，也有 ↺ ↻ 可以旋轉。

同類工具：PDF 整理

  • PDF 合併：把多個 PDF 合併成一個檔案，拖曳調整順序。
  • PDF 分割：依頁碼範圍拆分，或每頁存成一個檔案。
  • 刪除 PDF 頁面：刪除不要的頁面，可自動找出空白頁。
  • PDF 旋轉：旋轉單一頁面或整份 PDF，儲存後方向固定。
  • PDF 加頁碼：幫 PDF 每頁加上頁碼，支援「第 1 頁」中文格式。

HEIC 轉 PDF

把 iPhone 的 HEIC 照片轉成 PDF，多張合併成一個檔案。免費、免註冊、檔案不上傳。

🔒 檔案不會上傳，全程在您的瀏覽器中處理

⚠️ 您目前的瀏覽器可能無法讀取 HEIC。建議在 iPhone、iPad 或 Mac 上用 Safari 開啟本頁；JPG、PNG 不受影響。

    HEIC（也寫作 HEIF）是 iPhone 預設的照片格式，檔案比 JPG 小、畫質也好，但很多電腦和網站不支援。Waiting Studio 本機 PDF 的 HEIC 轉 PDF 可以把多張 HEIC 照片依序轉成一個 PDF，每張照片一頁，並可選擇紙張大小與邊界。為了確保檔案不上傳，本工具使用瀏覽器內建的影像解碼功能讀取 HEIC，因此需要支援 HEIC 的瀏覽器，例如 iPhone、iPad 與 Mac 上的 Safari。

    HEIC 轉 PDF怎麼做？4 個步驟完成

    1. 在 iPhone、iPad 或 Mac 上用 Safari 開啟本頁。
    2. 選擇或拖曳 HEIC 照片進來，可以一次選取多張，也可以和 JPG、PNG 混合。
    3. 調整順序、紙張大小與邊界。
    4. 按「轉換成 PDF 並下載」，儲存轉好的 PDF。

    電腦上的 HEIC 檔怎麼轉？

    Mac 的 Safari 可以直接讀取 HEIC，照上面的步驟操作即可。Windows 或 Chrome 目前大多無法在瀏覽器內解碼 HEIC，若您選擇的 HEIC 無法讀取，清單中會顯示提示。這時可以：在 iPhone 的「設定 > 相機 > 格式」選擇「最相容」，之後拍的照片就會是 JPG；或在 Mac 的「預覽程式」把照片輸出成 JPG，再使用 JPG 轉 PDF。我們刻意不使用需要上傳的轉檔服務，也不內建授權條款較嚴格的 HEIC 解碼函式庫。

    在手機上怎麼操作？

    1. 用 Safari 開啟本頁，點選上方區域，選擇「照片圖庫」並勾選照片。
    2. iPhone 在某些情況下會先把 HEIC 轉成相容的 JPG 再交給網頁（視相機格式與分享方式而定）；在 Safari 通常可以順利轉換，其他瀏覽器可能不支援 HEIC。
    3. 按「轉換成 PDF 並下載」。
    4. 到「檔案」App 的「下載項目」開啟 PDF。

    Android 手機若收到別人傳來的 HEIC 檔，目前多數 Android 瀏覽器無法在本機解碼，建議請對方改傳 JPG，或在 iPhone 上轉換。

    遇到問題怎麼辦？

    清單顯示「此瀏覽器無法讀取 HEIC」
    請在 iPhone、iPad 或 Mac 上用 Safari 開啟本頁。Windows 上的 Chrome、Edge 多半無法解碼 HEIC。
    從 iPhone 選照片時已經變成 JPG
    iOS 在把照片交給網頁時，可能會自動轉成相容格式，這種情況下照樣可以轉成 PDF。
    Windows 收到一整個資料夾的 HEIC
    可參考 Windows 上 HEIC 轉 PDF 的幾種做法。

    檔案怎麼在本機處理？

    本工具不內建 HEIC 解碼器，而是使用瀏覽器本身的影像解碼（Safari 支援 HEIC），讀取後在畫布上轉正並編碼成 JPG，再用 pdf-lib（MIT 授權） 放入 PDF。這樣做的好處是不必上傳照片，也不必使用授權條款較嚴格的 HEIC 函式庫；代價是只有支援 HEIC 的瀏覽器才能讀取。

    常見問題

    手機可以用嗎？

    iPhone、iPad 用 Safari 開啟最順利。Android 手機可以使用本站其他功能，但多數 Android 瀏覽器無法讀取 HEIC 檔。

    HEIC 是什麼？

    HEIC 是 Apple 從 iOS 11 開始採用的照片格式，同樣畫質下檔案約為 JPG 的一半，但在 Windows 和部分網站上不易開啟，所以常需要轉成 JPG 或 PDF。

    照片方向不對，要怎麼旋轉並儲存？

    轉換時會自動依拍攝方向轉正。若仍有頁面方向不對，可到 PDF 旋轉 調整後按「套用並下載 PDF」儲存。

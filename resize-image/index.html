    報名系統要求「照片寬 600 px」、網拍主圖要 1000×1000、社群貼文建議最長邊 1080，或是手機拍的照片方向轉錯了？Waiting Studio 本機 PDF 的圖片尺寸調整可以用三種方式改大小：限制最長邊（例如 1920 px）、依百分比（75%、50%、25%）或直接輸入寬高；同時可以順時針、逆時針旋轉 90 度、旋轉 180 度或水平翻轉。可一次選多張，清單會即時顯示調整後的寬高與檔案大小，多張打包成 ZIP 下載。

    圖片尺寸調整怎麼做？4 個步驟完成

    1. 選擇或拖曳圖片進來，可以一次選取多張。
    2. 選擇尺寸方式：限制最長邊、依百分比，或指定寬高（只填一邊會自動依比例計算）。
    3. 需要的話選擇旋轉角度、勾選水平翻轉，並選擇輸出格式。
    4. 按「調整並下載」：單張直接下載，多張打包成「調整尺寸圖片.zip」。

    為什麼用 Waiting Studio 本機 PDF？

    • 無次數限制：不限每天使用次數、不限檔案數量，也不會要求您「升級」才能繼續。
    • 免註冊、免安裝：打開網頁就能用，不需要帳號、Email 或安裝 App。
    • 無彈出視窗：不跳出廣告視窗、不在下載前插播，也不加浮水印。
    • 檔案不上傳：全部在本機處理，適合合約、報價單、身分證件掃描檔等敏感資料。

    iPhone／Android 手機怎麼用？

    不必安裝任何 App，用手機瀏覽器開啟本頁即可。以 iPhone 為例：

    1. 用 Safari 開啟本頁，點選上方區域，選擇「照片圖庫」並勾選照片。
    2. 選擇尺寸與旋轉方式，清單會顯示新的寬高。
    3. 按「調整並下載」，在下載提示中點選「下載」。
    4. 到「檔案」App 的「下載項目」開啟；可再分享到「照片」。

    Android 手機的操作方式相同：在 Chrome 開啟本頁，選取檔案時可以從「檔案」或「雲端硬碟」挑選，完成後檔案會存到「下載」資料夾。

    常見的尺寸要求

    一般網站與 Email 用最長邊 1920 px 就很清楚；社群貼文常用 1080 px；網拍商品圖常要求正方形，例如 1000×1000，可在「指定寬高」填入並取消「保持比例」（會拉伸變形，建議先裁成正方形）。勾選「保持比例」時，圖片會縮放到放得進您填的寬×高範圍內，不會變形。縮小尺寸會讓檔案明顯變小；放大（200%）不會增加細節，只會讓檔案變大。若主要目的是減少檔案大小，可以改用 圖片壓縮；要換格式請用 圖片格式轉換。

    怎麼做到「不上傳」？運作原理說明

    一般的線上 PDF 工具，會先把您的檔案上傳到對方的伺服器，處理完再讓您下載，檔案在網路上走了一趟，也會在別人的主機上停留一段時間。Waiting Studio 本機 PDF 的做法不同：整個網站只是一組靜態網頁，打開頁面時，瀏覽器會下載處理 PDF 所需的程式碼，之後用瀏覽器內建的影像解碼讀取圖片，在畫布上縮放、旋轉後重新編碼都由您裝置上的瀏覽器直接計算完成。

    我們使用開源函式庫 pdf-lib（MIT 授權）讀取與產生 PDF 結構，並用 Mozilla 開發的 PDF.js（Apache-2.0 授權）繪製頁面縮圖。這些程式碼都放在本站，不從第三方 CDN 載入；網頁也設定了內容安全政策（CSP），限制可載入的程式來源；處理檔案的程式碼不會把檔案傳到任何地方。處理完成的檔案是在瀏覽器記憶體中產生，再透過「下載」存到您的裝置，從頭到尾沒有任何上傳的動作。您可以打開瀏覽器的開發者工具，在「網路」分頁自行確認。

    常見問題

    檔案會上傳到伺服器嗎？

    不會。圖片尺寸調整的過程全部在您的瀏覽器中完成，本站沒有接收檔案的伺服器，也不會保存任何副本。關閉分頁後，記憶體中的資料就會清除。

    安全嗎？會不會被別人看到？

    因為檔案不會離開您的裝置，第三方無從取得內容。本站不使用 Cookie、不做追蹤分析，也不載入外部腳本。使用公用電腦時，記得處理完把下載的檔案刪除即可。

    檔案大小或數量有限制嗎？

    本站沒有設定大小或數量上限，能處理幾張、實際能處理多大的檔案，取決於您裝置的記憶體。檔案較大時，手機可能會變慢或記憶體不足，建議分批處理。

    需要註冊或付費嗎？

    不需要。所有功能免費、免註冊、無次數限制。未來可能在頁面中加入一個固定的廣告版位以維持營運，但不會有彈出視窗，也會提供付費移除廣告的選項。

    手機可以用嗎？

    iPhone、iPad 與 Android 手機都可以使用，建議用 Safari 或 Chrome 開啟。介面會自動調整成適合手機的版面，按鈕也加大方便點選。

    照片方向是歪的，旋轉後會正確嗎？

    新版瀏覽器會先依照片的 EXIF 方向資訊擺正再處理，輸出的圖片方向就是您在清單縮圖看到的方向；若仍不對，選擇旋轉角度即可。輸出不保留 EXIF。

    可以改成指定的 KB 大小嗎？

    尺寸調整控制的是寬高；要控制檔案大小，請到圖片壓縮選擇壓縮程度與最長邊，清單會即時顯示壓縮後的大小。

    改尺寸會讓畫質變差嗎？

    縮小時會使用瀏覽器的高品質縮放，JPG／WebP 以品質 92 重新編碼，肉眼通常看不出差別；PNG 為無損輸出。

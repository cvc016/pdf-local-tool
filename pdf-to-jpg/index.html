PDF 轉 JPG

把 PDF 頁面轉成 JPG 或 PNG 圖片。免費、免註冊、檔案不上傳。

🔒 檔案不會上傳，全程在您的瀏覽器中處理
選擇或拖放一個 PDF 檔案
檔案只在您的瀏覽器中轉換
輸出設定

想把 PDF 的某一頁貼到 LINE、簡報或社群貼文，或是報名網站只接受圖片檔時，就需要把 PDF 轉成圖片。Waiting Studio 本機 PDF 的 PDF 轉 JPG 會在瀏覽器中逐頁繪製 PDF，輸出 JPG 或 PNG，並可選擇 96、150、300 DPI 三種解析度，也可以只轉指定頁碼。只轉一頁時直接下載圖片，多頁時自動打包成一個 ZIP 檔，檔名會標示頁碼。

PDF 轉 JPG怎麼做？4 個步驟完成

  1. 選擇或拖曳一個 PDF 檔案進來。
  2. 選擇輸出格式（JPG 或 PNG）與解析度。
  3. 需要的話輸入頁碼，例如「1-3, 5」；留空代表全部頁面。
  4. 按「轉成圖片並下載」。

JPG 和 PNG 該選哪一個？

JPG 檔案較小，適合照片、掃描檔，以及要傳到 LINE 或社群的圖片；PNG 是無損格式，文字與線條的邊緣較銳利，適合表格、圖表或需要再編輯的截圖，但檔案較大。解析度方面，96 DPI 適合在螢幕上看，150 DPI 是清晰度與大小的平衡點，300 DPI 適合列印。若轉出的圖片太大，可以再用 圖片壓縮 縮小；反過來要把圖片做成 PDF，請使用 JPG 轉 PDF。

在手機上怎麼操作？

  1. 用 Safari 開啟本頁，點選上方區域，從「檔案」App 選擇 PDF。
  2. 選擇格式與解析度，若只要一頁請在頁碼欄輸入頁碼。
  3. 按「轉成圖片並下載」。
  4. 單張圖片可在「檔案」App 中分享到「照片」；多頁的 ZIP 點一下即可解壓縮。

手機上轉 300 DPI 的多頁檔案會比較慢，一般分享用 150 DPI 就很清楚。

遇到問題怎麼辦？

轉出的圖片字很糊
改用 300 DPI 或 PNG。若原本就是低解析度的掃描檔，轉換後也不會比原檔清楚。
300 DPI 轉很多頁時很慢
一頁 A4 在 300 DPI 約 2480×3508 像素，頁數多時會花比較久。分享到 LINE 或螢幕閱讀用 150 DPI 就夠清楚。
只想要其中一頁
在頁碼欄輸入那一頁的頁碼，例如「3」，就會直接下載單張圖片，不會打包 ZIP。

檔案怎麼在本機處理？

Mozilla 的 PDF.js（Apache-2.0 授權） 在您的瀏覽器裡依所選 DPI 把每一頁畫到畫布上，再由瀏覽器輸出成 JPG 或 PNG；多頁時用 fflate（MIT 授權）打包成 ZIP。PDF 與輸出的圖片都只存在您的裝置記憶體中，下載後即釋放。

常見問題

多頁 PDF 會變成幾個檔案？

每一頁一張圖片。超過一頁時會打包成一個 ZIP 檔方便下載，檔名會依頁碼排序，例如「檔名_第01頁.jpg」。

轉出來的圖片模糊怎麼辦？

請把解析度改成 300 DPI，或改用 PNG 格式。若原始 PDF 本身就是低解析度的掃描檔，轉換後也無法比原檔更清楚。

有密碼的 PDF 可以轉嗎？

需要開啟密碼的 PDF 目前無法讀取，請先用您有權限的軟體移除密碼後再轉換。

轉出的圖片有白色背景嗎？

有。PDF 頁面會畫在白底上，透明的部分會呈現白色。

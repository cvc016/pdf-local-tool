把 PDF 頁面轉成 JPG 或 PNG 圖片。免費、免註冊、檔案不上傳。

想把 PDF 的某一頁貼到 LINE、簡報或社群貼文，或是報名網站只接受圖片檔時，就需要把 PDF 轉成圖片。Waiting Studio 本機 PDF 的 PDF 轉 JPG 會在瀏覽器中逐頁繪製 PDF，輸出 JPG 或 PNG，並可選擇 96、150、300 DPI 三種解析度，也可以只轉指定頁碼。只轉一頁時直接下載圖片，多頁時自動打包成一個 ZIP 檔，檔名會標示頁碼。

PDF 轉 JPG怎麼做？4 個步驟完成

  1. 選擇或拖曳一個 PDF 檔案進來。
  2. 選擇輸出格式（JPG 或 PNG）與解析度。
  3. 需要的話輸入頁碼，例如「1-3, 5」；留空代表全部頁面。
  4. 按「轉成圖片並下載」。

為什麼用 Waiting Studio 本機 PDF？

  • 無次數限制：不限每天使用次數、不限檔案數量，也不會要求您「升級」才能繼續。
  • 免註冊、免安裝：打開網頁就能用，不需要帳號、Email 或安裝 App。
  • 無彈出視窗：不跳出廣告視窗、不在下載前插播，也不加浮水印。
  • 檔案不上傳：全部在本機處理，適合合約、報價單、身分證件掃描檔等敏感資料。

iPhone／Android 手機怎麼用？

不必安裝任何 App，用手機瀏覽器開啟本頁即可。以 iPhone 為例：

  1. 用 Safari 開啟本頁，點選上方區域，從「檔案」App 選擇 PDF。
  2. 選擇格式與解析度，若只要一頁請在頁碼欄輸入頁碼。
  3. 按「轉成圖片並下載」。
  4. 單張圖片可在「檔案」App 中分享到「照片」；多頁的 ZIP 點一下即可解壓縮。

Android 手機的操作方式相同：在 Chrome 開啟本頁，選取檔案時可以從「檔案」或「雲端硬碟」挑選，完成後檔案會存到「下載」資料夾。手機上轉 300 DPI 的多頁檔案會比較慢，一般分享用 150 DPI 就很清楚。

JPG 和 PNG 該選哪一個？

JPG 檔案較小，適合照片、掃描檔，以及要傳到 LINE 或社群的圖片；PNG 是無損格式，文字與線條的邊緣較銳利，適合表格、圖表或需要再編輯的截圖，但檔案較大。解析度方面，96 DPI 適合在螢幕上看，150 DPI 是清晰度與大小的平衡點，300 DPI 適合列印。若轉出的圖片太大，可以再用 圖片壓縮 縮小；反過來要把圖片做成 PDF，請使用 JPG 轉 PDF。

怎麼做到「不上傳」？運作原理說明

一般的線上 PDF 工具，會先把您的檔案上傳到對方的伺服器，處理完再讓您下載，檔案在網路上走了一趟，也會在別人的主機上停留一段時間。Waiting Studio 本機 PDF 的做法不同：整個網站只是一組靜態網頁，打開頁面時，瀏覽器會下載處理 PDF 所需的程式碼，之後用 PDF.js 把頁面繪製到畫布，再由瀏覽器輸出成 JPG 或 PNG 圖片都由您裝置上的瀏覽器直接計算完成。

我們使用開源函式庫 pdf-lib（MIT 授權）讀取與產生 PDF 結構，並用 Mozilla 開發的 PDF.js（Apache-2.0 授權）繪製頁面縮圖。這些程式碼都放在本站，不從第三方 CDN 載入；網頁也設定了內容安全政策（CSP），限制可載入的程式來源；處理檔案的程式碼不會把檔案傳到任何地方。處理完成的檔案是在瀏覽器記憶體中產生，再透過「下載」存到您的裝置，從頭到尾沒有任何上傳的動作。您可以打開瀏覽器的開發者工具，在「網路」分頁自行確認。

常見問題

檔案會上傳到伺服器嗎？

不會。PDF 轉圖片的過程全部在您的瀏覽器中完成，本站沒有接收檔案的伺服器，也不會保存任何副本。關閉分頁後，記憶體中的資料就會清除。

安全嗎？會不會被別人看到？

因為檔案不會離開您的裝置，第三方無從取得內容。本站不使用 Cookie、不做追蹤分析，也不載入外部腳本。使用公用電腦時，記得處理完把下載的檔案刪除即可。

檔案大小或數量有限制嗎？

本站沒有設定大小或數量上限，能轉換多少頁、實際能處理多大的檔案，取決於您裝置的記憶體。檔案較大時，手機可能會變慢或記憶體不足，建議分批處理。

需要註冊或付費嗎？

不需要。所有功能免費、免註冊、無次數限制。未來可能在頁面中加入一個固定的廣告版位以維持營運，但不會有彈出視窗，也會提供付費移除廣告的選項。

手機可以用嗎？

iPhone、iPad 與 Android 手機都可以使用，建議用 Safari 或 Chrome 開啟。介面會自動調整成適合手機的版面，按鈕也加大方便點選。

多頁 PDF 會變成幾個檔案？

每一頁一張圖片。超過一頁時會打包成一個 ZIP 檔方便下載，檔名會依頁碼排序，例如「檔名_第01頁.jpg」。

轉出來的圖片模糊怎麼辦？

請把解析度改成 300 DPI，或改用 PNG 格式。若原始 PDF 本身就是低解析度的掃描檔，轉換後也無法比原檔更清楚。

有密碼的 PDF 可以轉嗎？

需要開啟密碼的 PDF 目前無法讀取，請先用您有權限的軟體移除密碼後再轉換。

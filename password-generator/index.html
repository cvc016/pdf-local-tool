隨機密碼產生器

用密碼學安全亂數產生高強度密碼。免費、免註冊、密碼不會離開您的裝置。

🔒 檔案不會上傳，全程在您的瀏覽器中處理
密碼設定

    同一組密碼用在好幾個網站，是帳號被盜最常見的原因之一：只要其中一個網站外洩，其他帳號就跟著危險。Waiting Studio 本機 PDF 的隨機密碼產生器使用瀏覽器內建的 crypto.getRandomValues（密碼學安全亂數）產生密碼，可以設定長度、勾選大寫、小寫、數字與符號，也能排除 I、l、1、O、0、o 這些容易看錯的字元；每種勾選的字元至少會出現一次，並以位元熵顯示強度。密碼只在您的裝置上產生，本站不會看到、也不會儲存。

    隨機密碼產生器怎麼做？4 個步驟完成

    1. 選擇密碼長度，一般帳號建議 16 個字元以上。
    2. 勾選要使用的字元：大寫、小寫、數字、符號；需要手動輸入時可排除易混淆字元。
    3. 選擇要產生幾組，下方會立即列出密碼與強度。
    4. 按密碼旁的「複製」貼到註冊頁面，並存進您的密碼管理器；不滿意就按「重新產生」。

    為什麼用 Waiting Studio 本機 PDF？

    • 無次數限制：不限每天使用次數、不限檔案數量，也不會要求您「升級」才能繼續。
    • 免註冊、免安裝：打開網頁就能用，不需要帳號、Email 或安裝 App。
    • 無彈出視窗：不跳出廣告視窗、不在下載前插播，也不加浮水印。
    • 檔案不上傳：全部在本機處理，適合合約、報價單、身分證件掃描檔等敏感資料。

    iPhone／Android 手機怎麼用？

    不必安裝任何 App，用手機瀏覽器開啟本頁即可。以 iPhone 為例：

    1. 用 Safari 開啟本頁，調整長度與字元種類。
    2. 點選密碼旁的「複製」。
    3. 切換到要註冊或改密碼的 App 貼上。
    4. 把新密碼存到 iCloud 鑰匙圈或您的密碼管理器。

    Android 手機的操作方式相同：在 Chrome 開啟本頁，選取檔案時可以從「檔案」或「雲端硬碟」挑選，完成後檔案會存到「下載」資料夾。

    多長的密碼才夠安全？

    密碼強度取決於「長度」與「字元種類」。使用大小寫、數字與符號（約 88 種字元）時，每個字元約有 6.5 位元的不確定性：12 個字元約 78 位元，16 個字元約 103 位元，已遠超過目前暴力破解的能力。比起把密碼弄得很複雜，更重要的是每個網站使用不同的密碼，並開啟兩步驟驗證。記不住這麼多密碼時，請使用密碼管理器（例如 iCloud 鑰匙圈、Google 密碼管理工具或 Bitwarden）。若要把 Wi-Fi 密碼分享給客人，可以用 QR Code 產生器 做成 Wi-Fi QR Code。

    怎麼做到「不上傳」？運作原理說明

    一般的線上 PDF 工具，會先把您的檔案上傳到對方的伺服器，處理完再讓您下載，檔案在網路上走了一趟，也會在別人的主機上停留一段時間。Waiting Studio 本機 PDF 的做法不同：整個網站只是一組靜態網頁，打開頁面時，瀏覽器會下載處理 PDF 所需的程式碼，之後密碼產生都由您裝置上的瀏覽器直接計算完成。

    我們使用開源函式庫 pdf-lib（MIT 授權）讀取與產生 PDF 結構，並用 Mozilla 開發的 PDF.js（Apache-2.0 授權）繪製頁面縮圖。這些程式碼都放在本站，不從第三方 CDN 載入；網頁也設定了內容安全政策（CSP），限制可載入的程式來源；處理檔案的程式碼不會把檔案傳到任何地方。處理完成的檔案是在瀏覽器記憶體中產生，再透過「下載」存到您的裝置，從頭到尾沒有任何上傳的動作。您可以打開瀏覽器的開發者工具，在「網路」分頁自行確認。

    常見問題

    產生的密碼會被網站記錄嗎？

    不會。密碼是由您瀏覽器中的程式用密碼學安全亂數產生，沒有傳到任何伺服器，本站也不使用 Cookie 或追蹤分析。關閉或重新整理頁面後，密碼就消失了。

    需要註冊或付費嗎？

    不需要。所有功能免費、免註冊、無次數限制。未來可能在頁面中加入一個固定的廣告版位以維持營運，但不會有彈出視窗，也會提供付費移除廣告的選項。

    手機可以用嗎？

    iPhone、iPad 與 Android 手機都可以使用，建議用 Safari 或 Chrome 開啟。介面會自動調整成適合手機的版面，按鈕也加大方便點選。

    這樣產生的密碼真的隨機嗎？

    是的。本工具使用 Web Crypto API 的 crypto.getRandomValues，這是瀏覽器提供給加密用途的安全亂數，並用拒絕取樣避免某些字元出現機率偏高。

    網站說不能用某些符號怎麼辦？

    取消勾選「符號」，並把長度加長（例如 20 個字元）來維持強度。

    「位元熵」是什麼？

    代表猜中密碼需要嘗試的次數：每多 1 位元，可能組合就多一倍。本工具以「長度 × log2(字元池大小)」估算，72 位元以上為強。

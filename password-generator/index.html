密碼設定

    同一組密碼用在好幾個網站，是帳號被盜最常見的原因之一：只要其中一個網站外洩，其他帳號就跟著危險。Waiting Studio 本機 PDF 的隨機密碼產生器使用瀏覽器內建的 crypto.getRandomValues（密碼學安全亂數）產生密碼，可以設定長度、勾選大寫、小寫、數字與符號，也能排除 I、l、1、O、0、o 這些容易看錯的字元；每種勾選的字元至少會出現一次，並以位元熵顯示強度。密碼只在您的裝置上產生，本站不會看到、也不會儲存。

    隨機密碼產生器怎麼做？4 個步驟完成

    1. 選擇密碼長度，一般帳號建議 16 個字元以上。
    2. 勾選要使用的字元：大寫、小寫、數字、符號；需要手動輸入時可排除易混淆字元。
    3. 選擇要產生幾組，下方會立即列出密碼與強度。
    4. 按密碼旁的「複製」貼到註冊頁面，並存進您的密碼管理器；不滿意就按「重新產生」。

    多長的密碼才夠安全？

    密碼強度取決於「長度」與「字元種類」。使用大小寫、數字與符號（約 88 種字元）時，每個字元約有 6.5 位元的不確定性：12 個字元約 78 位元，16 個字元約 103 位元，已遠超過目前暴力破解的能力。比起把密碼弄得很複雜，更重要的是每個網站使用不同的密碼，並開啟兩步驟驗證。記不住這麼多密碼時，請使用密碼管理器（例如 iCloud 鑰匙圈、Google 密碼管理工具或 Bitwarden）。若要把 Wi-Fi 密碼分享給客人，可以用 QR Code 產生器 做成 Wi-Fi QR Code。

    在手機上怎麼操作？

    1. 用 Safari 開啟本頁，調整長度與字元種類。
    2. 點選密碼旁的「複製」。
    3. 切換到要註冊或改密碼的 App 貼上。
    4. 把新密碼存到 iCloud 鑰匙圈或您的密碼管理器。

    遇到問題怎麼辦？

    網站不接受某些符號
    取消勾選「符號」並把長度加長到 20 個字元以上，強度仍然足夠。
    需要手動輸入，怕看錯
    勾選「排除容易混淆的字元」，就不會出現 I、l、1、O、0、o。
    顯示「請至少勾選一種字元」
    大寫、小寫、數字、符號至少要勾一種。

    檔案怎麼在本機處理？

    密碼由瀏覽器的 Web Crypto API（crypto.getRandomValues）在您的裝置上產生，並用拒絕取樣避免字元機率不均。密碼不會傳到網路上，也不會儲存；按「重新產生」或重新整理後就不見了，請先存進密碼管理器。

    常見問題

    產生的密碼會被網站記錄嗎？

    不會。密碼是由您瀏覽器中的程式用密碼學安全亂數產生，沒有傳到任何伺服器，也不會被儲存。關閉或重新整理頁面後，密碼就消失了。

    這樣產生的密碼真的隨機嗎？

    是的。本工具使用 Web Crypto API 的 crypto.getRandomValues，這是瀏覽器提供給加密用途的安全亂數，並用拒絕取樣避免某些字元出現機率偏高。

    網站說不能用某些符號怎麼辦？

    取消勾選「符號」，並把長度加長（例如 20 個字元）來維持強度。

    「位元熵」是什麼？

    代表猜中密碼需要嘗試的次數：每多 1 位元，可能組合就多一倍。本工具以「長度 × log2(字元池大小)」估算，72 位元以上為強。

字數統計（中文字數計算）

貼上文字即時計算中文字數、英文單字、字元與段落。免費、免註冊、文字不上傳。

🔒 檔案不會上傳，全程在您的瀏覽器中處理

寫自傳、讀書計畫、作業、論文摘要或投稿時，常會遇到「500 字以內」「摘要 300 字」的限制；寫社群貼文、廣告文案時也要控制長度。Waiting Studio 本機 PDF 的字數統計會在您輸入或貼上文字時即時計算：中文字數、英文單字數、數字、標點符號、字元數（含與不含空白）、行數、段落數、UTF-8 位元組與預估閱讀時間。主要的「字數」採用常見的算法：每個中文字算 1 字，每個英文單字與每組數字各算 1 字，標點與空白不計。

字數統計怎麼做？4 個步驟完成

  1. 把文章貼到上方的文字框，或直接在裡面輸入。
  2. 下方會即時顯示字數、中文字、英文單字、字元數等統計。
  3. 依需求參考對應的數字：例如作業看「字數」，有字元上限的系統看「字元數」。
  4. 需要的話按「複製統計結果」，或按「清除文字」重新開始。

為什麼用 Waiting Studio 本機 PDF？

  • 無次數限制：不限每天使用次數、不限檔案數量，也不會要求您「升級」才能繼續。
  • 免註冊、免安裝：打開網頁就能用，不需要帳號、Email 或安裝 App。

iPhone／Android 手機怎麼用？

不必安裝任何 App，用手機瀏覽器開啟本頁即可。以 iPhone 為例：

  1. 用 Safari 開啟本頁，長按文字框選擇「貼上」。
  2. 下方會即時顯示各項統計。
  3. 修改文字時數字會跟著更新。
  4. 按「複製統計結果」可以把數字貼到備忘錄或訊息。

Android 手機的操作方式相同：在 Chrome 開啟本頁，選取檔案時可以從「檔案」或「雲端硬碟」挑選，完成後檔案會存到「下載」資料夾。

「字數」和「字元數」差在哪？

中文的「字數」通常指中文字的數量，英文則是單字數；「字元數」則是每一個字母、標點、空白都算 1。例如「Hello 世界！」字數是 3（1 個英文單字＋2 個中文字），不含空白的字元數是 8。學校作業、比賽徵文多半以字數計算，簡訊、表單欄位、程式資料庫的限制則多半是字元數或位元組。不同軟體對標點與數字的算法略有不同，若有嚴格上限，建議預留一點空間。整理好的文章要做成 PDF 繳交，可以搭配 PDF 合併 與 PDF 加頁碼。

怎麼做到「不上傳」？運作原理說明

一般的線上 PDF 工具，會先把您的檔案上傳到對方的伺服器，處理完再讓您下載，檔案在網路上走了一趟，也會在別人的主機上停留一段時間。Waiting Studio 本機 PDF 的做法不同：整個網站只是一組靜態網頁，打開頁面時，瀏覽器會下載處理 PDF 所需的程式碼，之後字數計算都由您裝置上的瀏覽器直接計算完成。

我們使用開源函式庫 pdf-lib（MIT 授權）讀取與產生 PDF 結構，並用 Mozilla 開發的 PDF.js（Apache-2.0 授權）繪製頁面縮圖。這些程式碼都放在本站，不從第三方 CDN 載入；網頁也設定了內容安全政策（CSP），限制可載入的程式來源；處理檔案的程式碼不會把檔案傳到任何地方。處理完成的檔案是在瀏覽器記憶體中產生，再透過「下載」存到您的裝置，從頭到尾沒有任何上傳的動作。您可以打開瀏覽器的開發者工具，在「網路」分頁自行確認。

常見問題

輸入的文字會上傳嗎？

不會。字數是由您瀏覽器中的程式即時計算，文字不會傳到任何伺服器，也不會被儲存；關閉分頁後就會清除。

需要註冊或付費嗎？

不需要。所有功能免費、免註冊、無次數限制。未來可能在頁面中加入一個固定的廣告版位以維持營運，但不會有彈出視窗，也會提供付費移除廣告的選項。

手機可以用嗎？

iPhone、iPad 與 Android 手機都可以使用，建議用 Safari 或 Chrome 開啟。介面會自動調整成適合手機的版面，按鈕也加大方便點選。

標點符號算字數嗎？

主要的「字數」不計標點與空白；標點數量另外列在「標點符號」，字元數則包含標點。

和 Word 算出來不一樣？

Word 會把連在一起的英數字算成一個字、中文字逐字計算，與本工具相近；但對全形符號、網址、Emoji 等的處理略有不同，差異通常只有幾個字。

日文、韓文可以算嗎？

可以。日文假名、韓文字會與中文字一樣逐字計算在「中文字」欄位中。

PDF 壓縮

把太大的 PDF 縮小，方便上傳與寄送。免費、免註冊、檔案不上傳。

🔒 檔案不會上傳，全程在您的瀏覽器中處理
選擇或拖放一個 PDF 檔案
檔案只在您的瀏覽器中壓縮，不會上傳
壓縮程度

壓縮會把每一頁轉成圖片，壓縮後的文字無法再選取或搜尋；需要保留文字時請保留原檔。

    報名表、履歷、掃描的證明文件常常一轉成 PDF 就好幾 MB，上傳到求職網站或政府平台時被「檔案超過大小限制」擋下來。Waiting Studio 本機 PDF 的 PDF 壓縮會在您的瀏覽器中把每一頁重新繪製成適當解析度的 JPG 圖片，再組回一個 PDF，對掃描檔與照片型 PDF 特別有效。可以選擇輕度、標準、強力三種程度，也能轉成灰階再縮小。壓縮完成會顯示前後大小；如果壓縮後沒有變小，會提醒您直接使用原檔。

    PDF 壓縮怎麼做？4 個步驟完成

    1. 選擇或拖曳一個 PDF 檔案進來。
    2. 選擇壓縮程度：一般建議「標準」，檔案仍太大再改「強力」。
    3. 黑白文件可勾選「轉成灰階」，通常還能再小一些。
    4. 按「壓縮 PDF 並下載」，確認畫面上的前後大小。

    為什麼用 Waiting Studio 本機 PDF？

    • 無次數限制：不限每天使用次數、不限檔案數量，也不會要求您「升級」才能繼續。
    • 免註冊、免安裝：打開網頁就能用，不需要帳號、Email 或安裝 App。
    • 無彈出視窗：不跳出廣告視窗、不在下載前插播，也不加浮水印。
    • 檔案不上傳：全部在本機處理，適合合約、報價單、身分證件掃描檔等敏感資料。

    iPhone／Android 手機怎麼用？

    不必安裝任何 App，用手機瀏覽器開啟本頁即可。以 iPhone 為例：

    1. 用 Safari 開啟本頁，點選上方區域，從「檔案」App 選擇 PDF。
    2. 選擇壓縮程度，按「壓縮 PDF 並下載」。
    3. 在下載提示中點選「下載」。
    4. 到「檔案」App 的「下載項目」找到「_已壓縮」結尾的 PDF。

    Android 手機的操作方式相同：在 Chrome 開啟本頁，選取檔案時可以從「檔案」或「雲端硬碟」挑選，完成後檔案會存到「下載」資料夾。頁數很多的檔案在手機上處理較慢，若出現記憶體不足，可以先用 PDF 分割拆成幾份再壓縮。

    壓縮的原理與限制

    本工具採用「把頁面轉成圖片」的方式壓縮，這是在瀏覽器裡、又不使用授權條款嚴格的函式庫時最可靠的做法。好處是掃描檔、照片型 PDF 通常能縮小一半以上；代價是壓縮後的文字變成圖片，無法再選取、複製或搜尋，也會失去超連結與表單欄位。若您的 PDF 是從 Word 直接匯出、以文字為主，它通常已經很小，壓縮反而可能變大，這時本工具會提醒您保留原檔。需要再縮小時，也可以先用 刪除 PDF 頁面 移除不需要的頁面。

    怎麼做到「不上傳」？運作原理說明

    一般的線上 PDF 工具，會先把您的檔案上傳到對方的伺服器，處理完再讓您下載，檔案在網路上走了一趟，也會在別人的主機上停留一段時間。Waiting Studio 本機 PDF 的做法不同：整個網站只是一組靜態網頁，打開頁面時，瀏覽器會下載處理 PDF 所需的程式碼，之後用 PDF.js 把每一頁繪製成圖片、以 JPG 重新編碼，再用 pdf-lib 組成新的 PDF都由您裝置上的瀏覽器直接計算完成。

    我們使用開源函式庫 pdf-lib（MIT 授權）讀取與產生 PDF 結構，並用 Mozilla 開發的 PDF.js（Apache-2.0 授權）繪製頁面縮圖。這些程式碼都放在本站，不從第三方 CDN 載入；網頁也設定了內容安全政策（CSP），限制可載入的程式來源；處理檔案的程式碼不會把檔案傳到任何地方。處理完成的檔案是在瀏覽器記憶體中產生，再透過「下載」存到您的裝置，從頭到尾沒有任何上傳的動作。您可以打開瀏覽器的開發者工具，在「網路」分頁自行確認。

    常見問題

    檔案會上傳到伺服器嗎？

    不會。PDF 壓縮的過程全部在您的瀏覽器中完成，本站沒有接收檔案的伺服器，也不會保存任何副本。關閉分頁後，記憶體中的資料就會清除。

    安全嗎？會不會被別人看到？

    因為檔案不會離開您的裝置，第三方無從取得內容。本站不使用 Cookie、不做追蹤分析，也不載入外部腳本。使用公用電腦時，記得處理完把下載的檔案刪除即可。

    檔案大小或數量有限制嗎？

    本站沒有設定大小或數量上限，能壓縮多少頁、實際能處理多大的檔案，取決於您裝置的記憶體。檔案較大時，手機可能會變慢或記憶體不足，建議分批處理。

    需要註冊或付費嗎？

    不需要。所有功能免費、免註冊、無次數限制。未來可能在頁面中加入一個固定的廣告版位以維持營運，但不會有彈出視窗，也會提供付費移除廣告的選項。

    手機可以用嗎？

    iPhone、iPad 與 Android 手機都可以使用，建議用 Safari 或 Chrome 開啟。介面會自動調整成適合手機的版面，按鈕也加大方便點選。

    壓縮後文字還能選取嗎？

    不行。為了讓檔案變小，每一頁會轉成圖片，文字、超連結與表單欄位都無法再編輯或搜尋。需要保留文字的場合（例如要讓對方複製內容），請保留原檔。

    為什麼壓縮後反而變大？

    以文字為主、由文書軟體直接匯出的 PDF 本來就很精簡，轉成圖片反而會增加大小。這時建議直接使用原檔；本工具偵測到檔案沒有變小時也會提醒您。

    要壓到 200KB／1MB 以下該選哪一個？

    先試「標準」，若仍超過限制再改「強力」並勾選灰階。頁數越多越難壓小，可以先刪除不需要的頁面或分成幾個檔案上傳。
